## 核心结论

这一讲把“图像分类”拆成三层：任务本身、数据驱动方法、以及第一个可学习的参数化模型。图像在计算机里只是 $[0,255]$ 的张量，语义鸿沟叠加视角、光照、遮挡、形变和类内差异，让手写规则几乎不可能，于是转向数据驱动。最近邻是最简单的数据驱动方法，但训练 $O(1)$、预测 $O(N)$，方向恰好反了，而且像素级距离没有语义，CIFAR-10 上 $k\approx7$ 也只有约 28%。线性分类器改成学习参数 $W$，可以用模板和超平面两种视角理解它，再用 softmax 加负对数似然把分数变成概率与损失；如何最小化这个损失，是下一讲的内容。

## 本讲路线 [00:05 - 01:43]

上一讲的课程地图把内容分成三块：深度学习基础、感知与理解视觉世界、重建并与视觉世界交互，最后落到以人为中心的 AI。今天只覆盖课表最前面的三项：**data-driven approaches**、**linear classification** 和 **K-nearest neighbor**。图像分类会在整个学期反复出现，因为它既是核心任务，也是讲清算法最好的基准；其他数据驱动方法放在备用 slides 里。

## 图像分类与语义鸿沟 [01:43 - 05:41]

任务定义很干净：给定一张图像和一组预设标签（dog、cat、truck、plane……），系统输出其中一个标签。对人来说这是瞬间完成的整体判断，对计算机则是另一回事。

彩色图像是三维张量：分辨率 800×600、RGB 三个通道，就是 $800\times600\times3$ 个整数，取值 0 到 255。这是 8 bit 的存储约定，RGB 常见为 24 bit（每通道 8 bit），32 bit 则多了 alpha 通道。一个像素的数值同时取决于表面材质颜色和光源，这一点在后面会变成“光照”这个挑战。

同一个语义对象，在人眼里是“猫”，在机器眼里是几百万个整数。这个落差就是 **semantic gap**，也是整门课要处理的核心困难。

## 让分类变难的那些变化 [05:26 - 10:41]

讲者用一只猫串起了所有挑战，其中一部分是现场同学答出来的。

- **视角变化**：相机绕着一动不动的猫平移，$800\times600\times3$ 里每个像素值都会变。人看来还是同一只猫，机器看来是一个全新的数据点。
- **光照**：RGB 值是材质与光源的函数，同一只猫在暗房间和太阳下数值完全不同。
- **背景杂乱**：背景物体混进画面。
- **尺度**：镜头推近拉远，物体在图像里的大小改变。
- **分辨率**：同学提到的这一项影响相对小，因为输入通常会被归一化到固定尺寸，除非伴随缩放效应。
- **遮挡**：只露出尾巴和一点爪子时，人靠“客厅沙发”的上下文判断是猫；脱离上下文，它也可能是老虎或尾巴很小的浣熊。
- **形变**：猫的身体极度柔软，同一只猫可以摆出无穷多种形状。
- **类内差异**：大小、颜色、花纹、品种都不同，全都还是猫。
- **上下文**：只看局部区块很容易判成老虎，阴影和场景线索才让答案变回猫。

真正要填的是那句 magic。历史上有人试过硬编码：先用 Canny 这样的边缘检测器找边缘，再找角点，统计特定类型的角点数量，最后映射到类别。这类方法只在变化极小的图像上有限成功，而且每识别一个新物体都要重写一遍规则，既难写又无法扩展。

**Machine learning** 换了一条路：不写逻辑，写流程。

1. 收集图像与标签组成数据集；
2. 用机器学习算法训练分类器，即实现 `train(images, labels)` 返回 model；

## 最近邻：把训练集背下来 [16:50 - 21:09]

**Nearest neighbor** 是最容易理解的数据驱动方法：`train` 什么也不学，只把训练数据和标签存进内存；`predict` 对每张测试图找最相似的那张训练图，直接复制它的标签。因此关键在于“相似”怎么定义，需要一个距离函数。

最常用的是 **L1 distance**（曼哈顿距离）：

$$
d_1(I_1,I_2)=\sum_p \left|I_1^p-I_2^p\right|
$$

把两张图逐像素相减、取绝对值、求和。课件上的示意就是两个 $4\times4$ 数字矩阵逐元素相减，再把差值全部加起来。

![最近邻分类器完整 Python 实现代码，包含 L1 距离计算与预测逻辑](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0011_00-20-14.jpg)

用 numpy 写出来只有几行：

```python
import numpy as np

class NearestNeighbor:
    def train(self, X, y):
        self.Xtr = X   # 训练只是把数据记下来
        self.ytr = y

    def predict(self, X):
        Ypred = np.zeros(X.shape[0], dtype=self.ytr.dtype)
        for i in range(X.shape[0]):
            distances = np.sum(np.abs(self.Xtr - X[i, :]), axis=1)  # L1
            Ypred[i] = self.ytr[np.argmin(distances)]
        return Ypred
```

课上还澄清了像素值的含义：它表示该位置的 RGB 强度，0–255 来自每通道 8 bit 的存储约定。

## 训练 O(1)、预测 O(N)：方向反了 [21:09 - 26:04]

复杂度是这一节的重点。训练只是保存一份数据，没有真正运算，所以是 $O(1)$；预测时每张测试图都要和全部 $N$ 张训练图算距离，是 $O(N)$。

问题在于方向反了。我们真正想要的是预测快、训练慢——训练可以离线慢慢做，预测却要在用户面前实时发生。讲者打了个比方：如果每次向 GPT 提问，它都去和互联网上所有可能的答案逐一比对，那要等好几年。GPU 加速和近似最近邻可以缓解，但超出本课范围；slide 上给出的工程实现是 **faiss**，以及 Johnson 等人 2017 年那篇 billion-scale similarity search 的工作。

## K 近邻与决策区域 [26:04 - 29:07]

把二维特征空间按“最近的训练样本是谁”染色，就得到 1-NN 的决策区域。视频里的图立刻暴露了问题：一片绿色包围中有一个黄点，它很可能是 outlier 或噪声，却凭一己之力切出一大块黄色区域。

解决办法是 **K-nearest neighbor**：不复制单个最近邻的标签，而是取最近的 $K$ 个点做多数投票。$K=3$ 时出现了白色区域——邻居来自不同类别、票数相同，无法决策。这些区域不是缺陷，而是提示：它们正是值得去补采数据的地方。真遇到平票时，随机从票数最高的类别里选一个。

## L1 与 L2：两种距离 [29:07 - 35:08]

距离函数可以换。**L2 distance**（欧氏距离）先平方、再求和、再开方：

$$
d_2(I_1,I_2)=\sqrt{\sum_p \left(I_1^p-I_2^p\right)^2}
$$

把“到原点距离相同”的点画出来，L1 得到方形，L2 得到圆——一个沿坐标轴走，一个走直线。

这个几何差异有实际后果。坐标轴就是特征：旋转特征轴时，L1 的等距形状跟着转、距离值会变；L2 的圆转完还是圆，距离不变。所以当特征本身含义明确、希望保留其结构时，L1 更合适；特征比较任意时，L2 更自然。把两种距离代回 1-NN，L1 的决策边界大多与坐标轴平行，L2 的边界更平滑。

## 超参数：只能靠验证集来选 [35:08 - 41:29]

$K$ 和距离函数都是 **hyperparameter**：它们不是训练出来的，而是运行算法前必须做的选择，且高度依赖数据集和问题。视频列了四种做法，逐渐变好：

1. 在训练集上选最好的。对 kNN 来说这是灾难：$K=1$ 在训练集上永远 100%，但它只是在背答案。
2. 在测试集上选。这等于作弊，测出的数字无法说明模型在新数据上的表现，讲者强调绝对不要这么做。
3. 划出 **validation set**：在训练集上训练，在验证集上选超参数，最后才在测试集上跑一次。
4. **Cross-validation**：把训练数据分成 5 折，每折轮流当验证集，跑 5 次取平均。更可靠，但代价是 5 倍计算；大规模深度学习里因此并不常用，实践中往往靠经验和单个验证集。论文里则经常要求交叉验证，以保证结果可复现。

验证集本身也有局限：它通常比训练集小得多，未必能代表整体分布，这正是交叉验证存在的理由。

## CIFAR-10：kNN 能做到什么程度 [41:29 - 46:26]

CIFAR-10 是后续作业会反复用到的数据集：10 个类别、50,000 张训练图、10,000 张测试图，每张 $32\times32\times3$。对每张测试图取最近的前 10 个邻居，可以看到大量错误。

用 5 折交叉验证扫 $K$，最好的取值在 7 附近，准确率约 28–29%。10 分类的随机猜测是 10%，所以它确实学到了东西，但离可用还很远。错误很有代表性：一张青蛙的最近邻可能是狗，因为两者在像素层面颜色分布相近。

最说明问题的是那组对比图：原图，以及染色、遮挡、平移一个像素的三张图，人眼差别巨大，但它们与原图的像素距离完全相同。结论很直接：**像素距离不具备语义信息**，kNN 加像素距离在真实应用中从不使用。

## 线性分类器：参数化方法 [46:26 - 50:04]

**Linear classifier** 换了一种思路：不再保存训练集，而是学一组参数 $W$。

把 $32\times32\times3$ 的图像拉平成 3072 维向量 $x$，10 个类别需要 10 个分数，于是 $W$ 是 $10\times3072$ 的矩阵：

$$
f(x,W)=Wx+b
$$

输出的 10 个数可以理解为这张图属于每个类别的分数。$b$ 是 **bias**，与输入无关，只为每个类别的分数提供偏移；几何上它让决策边界不必穿过原点，分类更灵活。

线性函数是神经网络最重要的积木：把线性变换一层层接起来，再加上非线性，就是深度网络。看主流架构会发现线性层无处不在。

## 三种视角看同一个 W [50:04 - 54:58]

视频用一个小例子（$2\times2$ 图像、4 个像素、cat/dog/ship 三类）把同一个 $W$ 讲了三遍。

- **代数视角**：$W$ 的每一行与 $x$ 做点积得到一个类别的分数，加上 $b$ 就是输出。
- **视觉视角**：$W$ 的每一行可以还原成一张同尺寸的图，即该类别的 **template**。在 CIFAR-10 上训练后，car 的模板隐约能看出车头轮廓，而这只是一个线性模型。
- **几何视角**：每一行是一个超平面，$f=0$ 就是该类与其余类的决策边界；二维时是直线，高维时是超平面。没有 bias 时所有边界都过原点，这显然不合理，bias 让边界可以平移。

线性分类器也有明确的失败模式：第一、三象限为一类而第二、四象限为另一类；到原点距离在 1 与 2 之间的圆环为一类；三个分离的簇为一类。这些都无法用一组超平面切开，这正是后面需要多层网络的原因。

## 损失函数：给 W 打分 [54:58 - 57:29]

$W$ 有无数种取法，怎么知道哪个好？需要一个 **loss function**（也叫 objective），量化当前分类器在训练数据上有多糟。给定数据集 $\{(x_i,y_i)\}_{i=1}^N$，数据集损失是每个样本损失的平均：

$$
L=\frac{1}{N}\sum_{i=1}^N L_i\left(f(x_i,W),y_i\right)
$$

接下来要高效地找到让 $L$ 最小的参数，也就是 **optimization**——那是下一讲的主题。这一讲先把 $L_i$ 定下来。

## Softmax：把分数变成概率 [57:29 - 62:34]

对 cat/car/frog 三类，线性模型给出 3.2、5.1、−1.7。这些分数无界、不可解释，**softmax** 把它们变成概率：

$$
P(Y=k\mid X=x_i)=\frac{e^{s_k}}{\sum_j e^{s_j}}
$$

先取指数保证非负，再除以总和保证和为 1。例子里得到 24.5、164.0、0.18，归一化后是 0.13、0.87、0.00：这组 $W$ 认为图是猫的概率只有 13%，明显错了。原始分数 $s$ 因此被称为 **logits**（未归一化的对数概率）。整个结构与 logistic regression 一致，多类别时叫 multinomial logistic regression。

训练目标是让正确类的概率尽量大。最大化不便直接优化，于是取负、再取对数，得到

$$
L_i=-\log\left(\frac{e^{s_{y_i}}}{\sum_j e^{s_j}}\right)
$$

这就是 softmax loss，也叫 cross-entropy loss。正确类概率接近 1 时损失接近 0；正确类概率被压得极低时损失迅速变大。

## 同一个损失的三种解释 [62:34 - 64:54]

这个负对数可以从三个角度理解。

- **最大似然**：选择让观测数据出现概率最大的参数，即 **maximum likelihood estimation**，与 CS229 里讲的是同一件事。
- **KL 散度**：把模型输出的分布与真实分布（正确类为 1 的 one-hot）比较，最小化 **KL divergence**。
- **交叉熵**：交叉熵等于 KL 散度加上真实分布的熵；one-hot 的熵为 0，于是交叉熵直接退化成负对数。深度学习框架里的 cross entropy 与 binary cross entropy 都是这套框架。

## 两个小问题与下一讲 [64:54 - 66:54]

讲者用两个问题检查理解。第一，softmax loss 的最小值和最大值是多少？最小是 0（正确类概率为 1），最大是无穷（正确类概率趋于 0，取负对数后发散）。第二，初始化时 $W$ 接近随机，所有分数几乎相等，每类概率约 $1/C$，此时损失是多少？代入得

$$
L_i=-\log\frac{1}{C}=\log C
$$

$C=10$ 时约等于 2.3。这个数字很实用：训练刚开始时 loss 应该接近 $\log C$，差得很远多半说明代码有问题。

下一讲在这个损失上加正则化，并讲怎么真正把它优化下去。

- **kNN 的收尾更明确**：2026 课件用 “k-Nearest Neighbor with pixel distance is never used” 收束，并配 original / occluded / shifted (1 pixel) / tinted 四张图说明像素距离相同；视频口述的是三张对比图（颜色、遮挡、平移一个像素）。
- **softmax 数值链路完整呈现**：2026 课件把 3.2/5.1/−1.7 → 24.5/164.0/0.18 → 0.13/0.87/0.00 → $L_i=2.04$ 全画在页面上，并标注 Maximum Likelihood Estimation（See CS229）；结尾用 Q1/Q2（$\log C\approx2.3$）和 “Coming up: Regularization, Optimization” 收尾，与视频一致。
- **KL 与交叉熵没有独立页面**：视频里讲者口述的 KL 散度、交叉熵、BCE 等价关系，在 2026 课件中只有 “compare probabilities / correct probs” 一页承载，2026 没有单独推导。

## 要点回顾

- 图像分类是给定图像与标签集合输出一个标签；图像对机器只是 $[0,255]$ 的张量，**semantic gap** 是根本困难。
- 视角、光照、背景杂乱、尺度、分辨率、遮挡、形变、类内差异与上下文，共同让硬编码规则不可行。
- 数据驱动三步：收集数据、`train` 得到模型、`predict` 评估新图像。
- 最近邻的 `train` 只保存数据，`predict` 找最近样本复制标签；**L1 distance** 是像素差绝对值之和。
- kNN 的训练是 $O(1)$、预测是 $O(N)$，与“预测要快、训练可离线”的需求相反；工程上用近似最近邻与 faiss 缓解。
- 1-NN 会被离群点切出大片错误区域；K 近邻用多数投票变稳健，平票的白色区域提示该补数据。
- L1 的等距形状是方形、L2 是圆；旋转特征轴时 L1 距离改变而 L2 不变，因此 L1 更适合特征有明确含义的场景。
- $K$ 与距离函数都是 **hyperparameter**；在训练集上选会退化成 $K=1$，在测试集上选是作弊，正确做法是验证集或交叉验证。
- CIFAR-10 上 kNN 最优 $K\approx7$、准确率约 28–29%；像素距离无语义，所以 kNN 加像素距离从不真正使用。
- 线性分类器是参数化方法：$f(x,W)=Wx+b$，$W$ 为 $10\times3072$，$b$ 让决策边界可以不过原点。
- 同一个 $W$ 有三种读法：代数（点积）、视觉（类别模板）、几何（超平面与决策边界）；它无法处理异或式、圆环式与多峰分布。
- softmax 把 logits 变成概率，损失是正确类概率的负对数；它与最大似然、KL 散度、交叉熵是同一件事，初始化时损失应约为 $\log C$。
