# CS231n Spring 2025 · Lecture 2 图像分类：数据驱动方法、K 近邻与线性分类器

**核心结论**：本讲正式定义图像分类任务——给一张图与一组预设标签，让机器输出其中一个标签，并指出计算机看到的是 0–255 的像素张量而非「猫」这一概念，二者之间的语义鸿沟叠加视角、光照、遮挡、形变、类内差异与上下文变化，使「写 if-else 规则」的硬编码路线行不通。取而代之的是数据驱动范式：收集图像与标签、用机器学习训练分类器、在新图上评估。本讲先用最简单的 K 近邻作教具，讲清 L1／L2 距离、训练 $O(1)$ 与预测 $O(N)$ 的不对称、决策边界、K 值与距离度量这两个超参数，以及训练集／验证集／测试集与交叉验证的规矩；再转向几乎全部深度学习基石的线性分类器 $f(x,W)=Wx+b$，从代数、视觉（类别模板）、几何（超平面）三种视角理解它，最后定义损失函数、用 Softmax 把无界分数变成概率分布，以负对数似然／交叉熵作为优化目标——如何求出最优 $W$ 则留给下一讲。

## 2. 图像分类任务、语义鸿沟与识别挑战 [02:45 - 14:45]

### 2.1 任务定义与语义鸿沟 [02:45 - 05:00]

给定一张图像和一组预先确定的标签（例子里是 dog、cat、truck、plane 等），系统的工作是把其中一个标签赋给这张图。对人类而言这是瞬间完成的事，因为认知系统天生会对图像做整体性理解；但对代码而言完全是另一回事。图像在计算机里是矩阵、更一般地是张量：一张 800×600 的彩色图有 RGB 三个通道，因此是 $800 \times 600 \times 3$ 的张量，每个像素值在 0 到 255 之间（8 bit，RGB 合起来是 24 bit 格式，有时再加一个 alpha 通道成 32 bit）。人看到的是「猫」，机器看到的是一堆整数——这就是语义鸿沟（Semantic Gap）。

下面这张幻灯片把猫的局部放大成一格格 0–255 的整数矩阵，直观说明「What the computer sees」与人的感知完全不同。

![语义鸿沟问题：猫图片局部放大显示为像素整数矩阵，说明图像是\[0,255\]的张量](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0002_00-04-28.jpg)

### 2.2 视角、光照、遮挡、形变、类内差异与上下文 [05:00 - 10:41]

一旦承认机器只在像素上做运算，各种变化就都成了挑战。讲者现场与学生一起枚举：平移／转动相机（哪怕猫一动不动，800×600×3 的每个像素值都会变，对计算机就是一个全新数据点）；光照（RGB 值是表面材质颜色与光源的函数，暗房里和阳光下的同一只猫数值差异很大）；背景杂乱（background clutter，物体与背景混在一起）；尺度／缩放（zoom in/out）；分辨率（不过模型通常会把图像归一化到统一尺寸，影响相对小）；遮挡（occlusion，右边那张只露出一截尾巴和爪子，人靠「客厅沙发」这一上下文仍能判断是猫，算法却容易误判成老虎或浣熊）；形变（deformation，猫身体可弯可扭）；类内差异（intraclass variation，不同大小、颜色、花纹、品种仍都是猫）；以及上下文（context）本身——孤立看局部容易被带偏，结合场景与阴影才分得对。

### 2.3 为什么无法硬编码规则：边缘／角点检测的局限 [10:41 - 14:45]

计算机科学里排序算法有清晰的 if-then-else 流程图，但视觉理解没有——你无法把「识别猫」硬编码成一串规则。历史上确有人尝试：先做边缘检测（find edges），再找角点（find corners），统计特定类型角点的数量或提取角点周围特征，最后映射到输出类别。课件引的是 John Canny, "A Computational Approach to Edge Detection", IEEE TPAMI 1986。

![基于边缘和角点检测的图像特征提取流程示意图，展示了从猫的图片到抽象符号的过程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0005_00-13-24.jpg)

这类方法在变化极小的图像上有些成功，但有两个致命问题：一是难扩展——每识别一个新物体都得重新设计一套规则；二是为每类找逻辑本身就很费功夫。正因如此，基于规则／过程的方法并未真正成功，机器学习才带来数据驱动这一新范式。

## 3. 数据驱动范式：三步流程 [14:41 - 17:26]

数据驱动把「写规则」换成「从数据里学」，标准流程是三步：① 收集图像及其标签的数据集（十几二十年前靠搜索引擎／图片搜索逐张攒，如今各类数据集已现成）；② 用机器学习算法训练分类器，即实现一个 `train(images, labels)` 函数，输入训练图像与标签、输出模型；③ 在新图像上评估，即实现 `predict(model, test_images)`，对未参与训练的图像返回预测标签。课件用 CIFAR-10 的飞机、汽车、鸟、猫、鹿等类别图作为训练集示例。

## 4. 最近邻与 K 近邻分类器 [16:50 - 29:07]

### 4.1 train 只是记忆，predict 才是全部工作 [16:50 - 20:15]

最近邻是最简单的分类形式：`train` 不做任何事，只把全部训练数据与标签存进内存，建一张查找表；`predict` 时把待测图与每张训练图比较，找出最相似的一张，输出它的标签。要比较就得有距离函数，最常用的是 L1 距离（曼哈顿距离），定义为两张图逐像素差值的绝对值之和：

$$d_1(I_1, I_2) = \sum_p |I_1^p - I_2^p|$$

做法是逐像素相减、取绝对值、再全部加起来，得到一个标量作为两图距离。这个定义极简，却在后面课程里被反复用到。

### 4.2 Python 实现与复杂度：训练 O(1)、预测 O(N) [20:15 - 25:34]

借助 numpy 只需几行就能实现，`predict` 对每个测试样本算它与所有训练样本的距离，取 `argmin` 对应的标签：

```python
import numpy as np
class NearestNeighbor:
  def train(self, X, y):
    self.Xtr = X
    self.ytr = y
  def predict(self, X):
    num_test = X.shape[0]
    Ypred = np.zeros(num_test, dtype = self.ytr.dtype)
    for i in xrange(num_test):
      distances = np.sum(np.abs(self.Xtr - X[i,:]), axis = 1)
      min_index = np.argmin(distances)
      Ypred[i] = self.ytr[min_index]
    return Ypred
```

下面是课件给出的完整实现与「With N examples, how fast are training and prediction?」的提问。

![Nearest Neighbor classifier 的 Python 实现代码及训练预测复杂度提问](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0007_00-23-07.jpg)

用大 O 记号分析：训练是 $O(1)$，因为只是把数据拷进内存、没有任何运算；预测是 $O(N)$，因为每张测试图都要和 N 张训练图逐一算距离。这个不对称很糟糕——讲者类比成「每次问 GPT 一个问题，它都要把答案和互联网上所有可能回答比对一遍，几年后才回你」。我们真正想要的是预测快、训练可以慢（训练能离线做）；用 GPU 等加速最近邻的工作超出本课范围。

![K近邻分类器的Python实现代码及训练预测复杂度分析](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0008_00-25-34.jpg)

顺带回答了线上学生的疑问：像素值是 0–255，是因为 RGB 24 bit 格式给红、绿、蓝每个通道 8 bit，共能组合出所有颜色，这是网上图像最通行的标准。

### 4.3 决策空间划分、离群点与 K 近邻投票 [25:34 - 29:07]

把二维特征空间里的每个训练点按「谁是最近邻」染色，就得到最近邻的空间划分：落在某区域中的测试点，其颜色即预测类别。问题一眼可见——中间那个黄色点被一堆绿点包围，几乎肯定是噪声／离群点，却因为只用 1 个近邻而撑出一整块黄色区域。为更稳健，改为取 K 个近邻并做多数投票（majority voting），这就是 K-Nearest Neighbors。代价是出现白色区域：那里来自不同类别的近邻票数相等，无法判定标签，也正好提示「这些模糊区域该去多采集数据」。K 越大边界越平滑，但白色平票区也可能随之变化。

## 5. 距离度量：L1 曼哈顿与 L2 欧氏 [29:07 - 35:26]

除了 K，另一个要定的超参数是距离函数。L1（Manhattan）的等距线是一个菱形／正方形：正方形边界上各点到原点距离相同，因为它只允许沿坐标轴上下左右走、不能走对角线（例如向上 0.5、向右 0.5，总距离仍是 1）。L2（Euclidean）则取差值平方和再开根号：

$$d_2(I_1, I_2) = \sqrt{\sum_p (I_1^p - I_2^p)^2}$$

其等距线是一个圆，圆上每点到中心距离相同。课件把两条公式与菱形／圆形几何示意并列给出，作为 KNN 最基本的两种距离函数：L1 对应菱形区域，L2 对应圆形区域。

![KNN距离度量对比：L1曼哈顿距离与L2欧氏距离公式及几何示意图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0009_00-30-10.jpg)

这套可视化还揭示更深的差别：x、y 轴在这里就是特征（若只有两个像素值便是二维特征空间）。旋转特征轴／换一组特征时，L1 的菱形会跟着变形、距离值随之改变，说明 L1 对特征取值很敏感；L2 的圆旋转后完全不变，对坐标系不敏感。因此当特征有明确含义、希望保留其信息时 L1 往往更好，特征更任意时 L2 更合理。用 K=1 分别在 L1 与 L2 下重画空间划分，L1 的边界大多平行于两条特征轴，L2 则更平滑。课程网站还提供在线工具可调 K 与距离函数观察划分变化。

## 6. 超参数调优与交叉验证 [35:26 - 41:29]

讲者专门借 KNN 引出「超参数（hyperparameters）」：为运行算法必须先做的决策，这里是 K 的取值与距离函数的选择；它们高度依赖数据集甚至具体问题，需要一套方法来定，即超参数调优（hyperparameter tuning）。课件依次否掉几种思路：

- Idea #1：选在训练数据上表现最好的超参数。坏主意——对最近邻而言 $K=1$ 永远能把训练集背下来，准确率 100%，毫无泛化意义。
- 在留出测试集上调更好一点，但仍是「作弊」：你针对测试集挑了最好的超参数，就无法知道模型在任何其它数据上的泛化能力，绝对不能这么做。
- 正确做法：从训练数据里再切出验证集（validation set），在 train 部分训练、在验证集上挑超参数，定好后再用这组超参数去测试集上做一次预测。

这张幻灯片展示的正是「在训练数据上挑最佳超参数」这第一种（不推荐的）思路。

![超参数设置幻灯片，展示在训练数据上选择最佳超参数的思路及train数据集框](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0011_00-37-05.jpg)

但单个验证集往往太小、未必能代表整体分布，于是有了交叉验证（Cross-Validation）：把训练数据切成若干折（folds，图中 5 折），每一折轮流当验证集、其余当训练集，跑 5 次把准确率平均，用平均值比较不同超参数，选定后才应用到测试集。它更可靠，但代价是要重复训练多次；在大规模深度学习里因为数据集太大、重复 5 次代价太高而不常用，通常改用单一验证集加经验，不过研究论文常要求这类统计流程以保证结果可复现。

![交叉验证示意图，展示5折数据划分及轮流作为验证集的过程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0012_00-40-13.jpg)

## 7. CIFAR-10 上的 KNN 结果与像素距离的失效 [41:29 - 46:26]

接着看真实结果。CIFAR-10 是作业里会反复用到的数据集，含 10 个类别及训练／测试图像。对每个测试图取 top 10 个最近邻可视化，用五折交叉验证扫描 K 值：图中 $K=7$ 附近准确率最高，约 28–29%。十分类问题随机猜只有 10%，所以确实学到了东西，但离可用还很远，错误很多——例如第四行明明是青蛙，最近的邻居却像狗，因为距离直接算在像素上，整体色调相近就被判为更近。

更说明问题的是这张图：原图、被遮挡、整体右移 1 像素、以及色调改变后的三张图，人眼看差异明显，但它们与原图的像素距离竟然相同。结论是——基于像素的距离度量不具信息量（Distance metrics on pixels are not informative），带像素距离的 KNN 在图像分类里从不使用。

![演示基于像素距离的KNN算法失效案例：遮挡、平移和色调变化导致相同像素距离](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0013_00-44-14.jpg)

KNN 的总结规则由此定下：从训练集（图像＋标签）出发，在测试集上预测；预测依据是 K 个最近训练样本；距离度量与 K 都是超参数；用验证集选超参数；测试集只在最后运行一次（Only run on the test set once at the very end!）。讲者还补充，决策遇到平票时常随机选一个 top 结果；若在某类问题（如遗传学、医学影像）的特征空间里看到成片的模糊空白区，就该去找落在那一区域的新样本补数据。

![K近邻算法总结幻灯片，列出训练/验证/测试集使用规则与超参数选择](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0014_00-45-59.jpg)

## 8. 线性分类器：参数化方法、三种视角与局限 [46:26 - 55:05]

剩下的时间讲本讲最重要、也是几乎全部深度学习的基石——线性分类器。与「记住所有数据」的最近邻不同，它是参数化（parametric）方法：学一组权重 $W$（及偏置 $b$），把输入图像映射成各类别的成员分数（membership scores）。函数就是

$$f(x, W) = Wx + b$$

以 CIFAR-10 为例，一张 $32 \times 32 \times 3$ 的图拉直成 3072 个数，即 $x$ 是 $3072 \times 1$ 向量；10 个类别需要 10 个分数，输出是 $10 \times 1$；于是 $W$ 必须是 $10 \times 3072$，$b$ 是 $10 \times 1$。偏置是与输入无关的项，能给不同类别分数一个平移、帮助更好地分离各类；把多个这样的线性函数首尾相接，再加上其它组件，就堆成了大型神经网络——线性函数在各种主流架构里无处不在。

![线性分类器参数化方法示意图，展示图像输入、权重矩阵W和偏置b的计算过程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0015_00-49-09.jpg)

为直观看清这个映射，可把 32×32 缩成 2×2（四个像素）、类别简化成 cat／dog／ship 三类，看的还是同一个 $Wx+b$。三种等价视角：

- **代数视角**：$W$ 的每一行独立对应一个类别，与输入向量做点积再加偏置得到该类别分数。
- **视觉视角**：把 $W$ 的每一行重新排回图像形状，就是该类别学到的「模板（template）」；在 CIFAR-10 上训完后看 10 个类别的模板，car 那行隐约能看出车头。课件给出 airplane、automobile、bird、cat、deer、dog、frog、horse、ship、truck 十类模板及具体得分（如 −96.8、437.9、61.95）。

![线性分类器的视觉解释，展示不同类别的权重矩阵和得分计算结果](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0016_00-52-30.jpg)

- **几何视角**：在二维特征空间里，每一类对应一条令该行方程为 0 的直线，直线两侧分数一正一负；高维里就是超平面。偏置的作用在这里很清楚——没有它所有直线都必须过原点，显然不合理。

线性分类器虽是基石，却有明确局限：它画不出很多分布的分界面。例如第一、三象限为一类、第二、四象限为另一类；或「到原点距离在 1 到 2 之间」为一类、其余为另一类；或空间里有三块孤立区域同属一类、其余为另一类——这些都无法被线性分开。

## 9. 损失函数、Softmax 与交叉熵 [55:05 - 66:54]

模型结构定了，剩下的问题是：怎么选出那个能把每张图映射成正确分数的 $W$？需要定义损失函数（loss function／objective function）来量化「这个分类器有多差」——即讲者说的对训练分数「不满意的程度」；再找一种高效改变 $W$、把这份不满意降到最小的办法，那是优化，也是下一讲的主题。

形式化地，训练集为 $(x_i, y_i)$，单样本损失 $L_i(f(x_i,W), y_i)$ 比较预测分数与真实标签，整体损失按样本数取平均：

$$L = \frac{1}{N}\sum_i L_i(f(x_i, W), y_i)$$

定义 $L_i$ 的方式有多种，本讲以 Softmax 分类器为例。仍用 cat／car／frog 三类，某张猫图的原始分数是 3.2、5.1、−1.7。

![Softmax分类器示例：展示猫、车、青蛙三类样本的得分矩阵及损失函数定义公式](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0017_00-56-58.jpg)

这些分数无界、不可控，最好的处理是变成概率：先对每个分数取指数（保证恒正），再除以所有指数之和做归一化，得到和为 1 的概率分布：

$$P(Y=k \mid X=x_i) = \frac{e^{s_k}}{\sum_j e^{s_j}}, \qquad s = f(x_i; W)$$

课件演示从 (3.2, 5.1, −1.7) 经指数到概率 (0.13, 0.87, 0.00)——当前 $W$ 认为「是猫」的概率只有 13%，明显是错的，需要优化。这些未归一化的对数概率常被称为 logits；这正是逻辑回归（logistic regression）的框架，因为是多类，叫多项逻辑回归（multinomial logistic regression）。

![Softmax分类器（多项逻辑回归）：展示Logits经指数运算和归一化转换为概率分布的过程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0018_01-00-19.jpg)

损失的目标应是最大化「样本属于正确类别」的概率；但惯例是写成最小化问题，于是取负、再取 log 让数值更好处理，得到负对数似然：

$$L_i = -\log P(Y=y_i \mid X=x_i) = -\log\left(\frac{e^{s_{y_i}}}{\sum_j e^{s_j}}\right)$$

讲者指出这与 CS229 里的最大似然估计（maximum likelihood estimation）是同一套算法。

![Softmax分类器（多项逻辑回归）的公式推导与损失函数定义幻灯片](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0020_01-06-01.jpg)

它还有两种等价解读：从信息论看，是让预测概率分布去匹配真实的正确概率分布，即最小化 KL 散度（Kullback–Leibler divergence）；再进一步就是交叉熵，因为 $H(P,Q) = H(p) + D_{KL}(P\|Q)$，而真实标签用 one-hot 编码时 $H(p)=0$，交叉熵便化简成同一个负对数形式。这正是深度学习框架里常听到的 cross entropy／BCE（binary cross entropy）。

![交叉熵损失函数图解：对比预测概率与真实标签（one-hot）并展示KL散度分解](/coursenotes/cs231n-deep-learning-for-cv-sp25/l02-image-classification/kf_0019_01-04-47.jpg)

最后两个课堂提问：单个 $L_i$ 的最小值是 0（对应正确类概率为 1），最大可到无穷（概率趋 0 时 $-\log$ 发散）；若初始化时 $W$ 近似随机、各类概率近似相等，则每个约 $1/C$，损失约为 $\log C$——$C=10$ 时 $\ln 10 \approx 2.3$，正好可作为训练起始损失的 sanity check。优化这份损失以求出正确的 $W$，就是下一讲的内容。

## 要点回顾

- 图像分类＝给图＋预设标签输出一个标签；机器看到的是 $800\times600\times3$、0–255 的像素张量，与人感知的「猫」之间是语义鸿沟。
- 视角、光照、背景杂乱、尺度、遮挡、形变、类内差异、上下文等变化都会改写全部像素值，故 if-else／边缘角点（Canny 1986）式硬编码规则不可扩展，需转向数据驱动。
- 数据驱动三步：收集图像＋标签、`train` 训练分类器、`predict` 在新图上评估。
- 最近邻 `train` 只记忆（$O(1)$）、`predict` 与全部 N 张训练图比距离（$O(N)$）；L1 距离为逐像素绝对差之和。
- 1-NN 决策空间易被离群点扭曲；K-NN 多数投票更稳健，但会出现票数相等的白色平票区，提示该处应补数据。
- 距离度量 L1（曼哈顿，菱形等距线、对特征旋转敏感）与 L2（欧氏，圆形等距线、对坐标系不敏感）；有明确语义的特征倾向 L1，任意特征倾向 L2。
- 超参数是 K 与距离函数；不能在训练集（$K=1$ 恒 100%）或测试集（作弊）上调，应切验证集，小数据集用 5 折交叉验证，测试集只在最后跑一次。
- CIFAR-10 上 KNN 五折交叉验证 $K\approx7$ 最佳、约 28–29%（随机 10%）；像素距离把遮挡／平移／调色视作等距，故「基于像素的 KNN 从不使用」。
- 线性分类器 $f(x,W)=Wx+b$ 是参数化方法：32×32×3→3072×1，$W$ 为 10×3072，输出 10 类分数；代数／视觉（类别模板）／几何（超平面）三视角等价，偏置让分界面不必过原点，但无法分开异或式、环形等多峰分布。
- Softmax 用 $e^{s_k}/\sum_j e^{s_j}$ 把 logits 变成概率，损失取正确类的负对数（＝最大似然＝KL 散度＝交叉熵，one-hot 下 $H(p)=0$）；随机初始化时损失约 $\log C$，$C=10$ 为 $\ln10\approx2.3$；求最优 $W$ 属下一讲的优化。
