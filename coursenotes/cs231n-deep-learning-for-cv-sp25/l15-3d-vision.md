# CS231n Spring 2025 · Lecture 15 三维视觉：从几何表示到神经渲染

**核心结论**：本讲是课程十周年系列客座讲座之一，由斯坦福计算机科学系助理教授、Stanford Vision and Learning Lab 成员 Jajun Wu（讲者自称 Jun）主讲，研究涵盖场景理解、多模态感知、机器人与具身智能、视觉生成与推理，以及本讲主题 3D 理解。与 2D 图像天然就是像素矩阵不同，3D 对象有几何、纹理、材质，且尺度与细节跨度极大，因此「如何表示 3D」成为先于深度学习的核心问题：讲者系统梳理了显式表示（点云、网格、参数化曲面）与隐式表示（代数曲面、距离函数、水平集、体素）在「采样点」与「内外测试」上的根本权衡。随后按历史脉络讲深度学习如何进入 3D：从体素与 3D 卷积起步，经 ShapeNet 等数据集推动，到多视图 CNN、3D 原生生成网络、PointNet、AtlasNet，再到 2019 年前后「深度网络即隐式函数」的转向，最终落在 NeRF 的可微体渲染与 3D Gaussian Splatting 的效率突破。收尾把视线从几何细节移到结构：部件的对称性、重复与层级关系，以及用大语言模型输出程序来生成形状的新趋势。

## 1. 3D 表示总览：为什么表示是第一问题 [00:05 - 04:55]

讲者先说明本讲与前面几周很不一样：之前谈的是卷积网络、Transformer、视觉语言模型与生成模型，都作用在 2D 图像／视频上；而 3D 视觉要先花大量篇幅讲**表示**，再谈 AI 如何改变它，最后才看 3D 生成、重建等应用。

2D 之所以简单，是因为图像就是一个规整矩阵——载入一张 PNG/JPEG，得到 200×200 或 500×500 的像素值。3D 对象则不然：尺度可以从巨型建筑、树木到放大后才看得见的精细结构，还同时包含几何、纹理与材质。仅就几何而言，表示方式就分成两大类——**显式（explicit）**：点云、多边形网格、subdivision、NURBS 等，以某种方式直接给出物体上的点；**隐式（implicit）**：level sets、代数曲面、距离函数等，把几何写成函数，不如「一堆点」直观，却各有优劣。每种选择都对应最适合的特定任务／几何类型，在接入深度学习时也有各自的强项与弱点。

![几何表示方法的分类幻灯片，列举了显式（点云、网格）和隐式（代数曲面、距离函数）方法](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0001_00-03-35.jpg)

选择表示时要权衡一串实际操作：如何**存储**（像素是矩阵，点云不规则，隐式函数又该怎么存盘）、如何**创建**新形状（尤其当输入是一张图或一句语言描述时）、如何**编辑／简化／平滑／滤波／修补**、如何**渲染**成 2D 像素，以及如何做**动画**。某种意义上 3D 视觉就是在 invert 渲染过程——从 2D 图像反推 3D 物体。这些考量再加上与形状编辑、渲染、逆渲染、动画等深度学习方法的整合，构成了整条主线。

## 2. 显式表示：点云、网格与参数化曲面 [04:55 - 17:16]

### 2.1 点云：最简单也最原始 [04:59 - 08:28]

**点云**是最简单的表示，只含 3D 点、不含连接关系：不再有 $n\times n$ 的像素矩阵，而是一个 $3\times n$ 矩阵，三个分量是各点的 $xyz$ 坐标。有时还带上**表面法线**（点朝向哪个方向），这类带方向的点有时被称作 surfels；法线的作用是配合光源做真实感渲染——要知道来自某方向的光如何与点交互，画面才逼真。

点云常是深度传感器、3D 扫描仪乃至 iPhone（ARKit 类软件）扫描的**原始输出**，往往带噪声，需要配准、融合、修补才能得到带纹理的物体。它的好处是极其灵活：点可以随意移动，不受拓扑约束，适合形状差异极大的大数据集。局限也很明显：点采样可能不均匀（兔子头部密、尾部疏），需要专门算法保证各区域大致均匀；不方便直接做简化、细分；没有拓扑信息，给一堆点甚至分不清是环面还是环形结构；也不直接支持平滑渲染。

### 2.2 多边形网格：图形工业的主力 [08:28 - 11:12]

为补上连接关系，自然走向**多边形网格**：仍有点，但多了面与「点如何相连」，是图形引擎与电子游戏里使用最广的表示。代价是复杂度上升——原始网格里每个面的顶点数可能不同（三点、四点、五点），这种不规则性很难与早期假设固定分辨率的卷积网络对接，讲者认为这正是 3D 深度学习起步偏晚的原因：人们得先想办法把深度学习适配到这些不如图像统一的表示上。

网格可以非常精细：讲者举例一尊雕塑的网格含约 **5600 万个三角形、2800 万个顶点**，Google Earth 甚至用上万亿个三角形表示地球上所有建筑。它支持 subdivision（加面以捕捉更多细节）、simplification（减面以加速处理）与 regularization——把不规则网格整理成「每个面都是三角形、大小相近、各区域采样均匀」的形式，便于后续图形算法处理。

![网格正则化前后对比图，左侧稀疏右侧致密](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0002_00-10-46.jpg)

### 2.3 参数化曲面：用低维函数映射出 3D [11:12 - 14:16]

物体并不总是不规则的：椅子、桌子里的直线，用一堆点或网格表示会丢掉大量信息。**参数化表示**把形状写成函数，其依据是内在自由度往往很低——曲线只有 1 个自由度（变化 $x$ 得 $y$），曲面通常只有 2 个，把它们映射到 3D 空间即可。2D 里圆可以用 $\sin t,\cos t$ 表示；3D 里球面只需两个参数 $(u,v)$：

$$s: \mathbb{R}^2 \to \mathbb{R}^3,\quad s(u,v)=r\big(\cos u\cos v,\ \sin u\cos v,\ \sin v\big),\quad (u,v)\in[0,2\pi)\times[-\pi/2,\pi/2]$$

![参数化曲面示例：3D球面的映射定义与参数方程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0003_00-13-10.jpg)

更复杂的有 Bézier 曲线与曲面，用少数控制点就能表示灵活光滑的曲面，同样支持细分。于是表示又分出一条轴：**非参数化**（无序点集、网格）与**参数化**（变动少数底层自由度、经函数映射成复杂形状）。

### 2.4 显式表示的利弊：易采样、难做内外测试 [14:16 - 17:16]

前面这些都属于显式表示，共同优点是**采样极容易**：在参数空间随机取 $(u,v)$，过一遍函数就得到保证落在物体表面上的 3D 点。以环面为例，其参数方程为

$$f(u,v)=\big((2+\cos u)\cos v,\ (2+\cos u)\sin v,\ \sin u\big)$$

![显式曲面采样示例：环面（Torus）的参数方程与几何结构](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0004_00-15-34.jpg)

软肋则正好相反：**很难判断某个给定点在物体内部还是外部**。讲者用球面举例，采样容易，但面对查询点 $(3/4,\,1/2,\,1/4)$ 却不易回答内外。这在今天尤其成问题，因为大量新型神经渲染方法需要反复查询「某点在不在物体内、该点的几何／密度、材质、radiance 或颜色是什么」，显式表示对这类操作并不友好。

## 3. 隐式表示：内外测试、函数组合、水平集与体素 [17:16 - 27:19]

### 3.1 隐式函数：$f(x,y,z)=0$ 与内外测试 [17:16 - 20:47]

隐式表示换一个思路：不去给点，而是**对点做分类**。假设物体表面上的点满足某个约束 $f(x,y,z)=0$；单位球面上所有点满足 $x^2+y^2+z^2=1$，即

$$f(x,y,z)=x^2+y^2+z^2-1$$

复杂形状（比如一头牛）往往写不出闭式解，此时可以直接**用神经网络来表示 $f$**。这一思路起于几何，后来被扩展到纹理、材质、外观。隐式表示的坏处是采样难——要解 $f=0$ 才能拿到表面点，函数一复杂就无从下手；好处是**内外测试极其简单**：把查询点代入函数，输出为负即在内部、为正则在外部。

![隐式曲面内外测试示例，展示球体方程及点(3/4, 1/2, 1/4)的判定过程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0005_00-20-21.jpg)

幻灯片代入点 $(3/4,1/2,1/4)$ 得 $f=-1/8<0$，故判定「Yes, inside」。显式与隐式之间「易采样 ↔ 易内外测试」的清晰权衡，讲者认为是理解后续深度网络如何作用于 3D 数据的根本。

### 3.2 函数的组合与距离函数 [20:47 - 24:00]

隐式表示另一个优点是**易于组合**：因为每个函数对 $xyz$ 都返回一个数值，对这些值做算术运算就能实现并、交、差等逻辑操作，从而由简单形状拼出复杂形状——这正是工业 CAD 设计里制造复杂零件的做法。若用的是**距离函数**，正负数值还带有「离表面多远」的含义，把它们相加就能在形状之间平滑插值／混合：讲者用两条一维直线为例，两个函数相加自然得到二者的过渡，这类距离函数可以任意组合出细节丰富的复杂世界。

### 3.3 水平集方法与体素：把隐式「查」成矩阵 [24:00 - 27:19]

闭式隐式函数写复杂形状（牛）很困难，每次查询还要对几百个函数做加减逻辑，太慢。于是有了**水平集方法**：预先在 3D 空间取一个网格（例如 $100\times100\times100$，即 100 万个点），对每点预算它是内是外、离表面多远，把这些值存成一个 3D 矩阵。此时边界就落在「相邻两格一正一负」之间——中间必有满足 $f(x)=0$ 的点。这相当于把参数化的隐式表示转成**非参数化**表示，便于可视化与显式控制，广泛用于 CT、MRI 等医学数据。

![隐式水平集方法幻灯片，展示5x5数值网格及f(x)=0等值线示意图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0006_00-25-08.jpg)

再进一步：若根本不关心距离值、只关心内外，就把正值记为 1、负值记为 0 做二值化，得到**体素（voxels）**——一个 3D 矩阵，与 2D 像素矩阵高度类比。

![体素表示幻灯片，增加斯坦福兔的平滑网格与体素化对比图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0007_00-27-32.jpg)

从「像素是 2D 矩阵、体素是 3D 矩阵」这个角度看，体素反而最易理解；幻灯片用斯坦福兔的平滑网格与二值化体素化效果做了对照。

## 4. 深度学习为何从体素起步：3D 卷积、数据集与任务全景 [27:19 - 38:25]

### 4.1 从 2D 卷积到 3D 卷积 [27:19 - 29:29]

深度学习 2010 年前后由 Hinton 在语音识别上起步、2012 年 AlexNet 在 ImageNet 上爆发，全都在 2D。想把它搬到 3D 时，动手的是**计算机视觉研究者而非图形学研究者**：他们最熟悉像素，最省事的类比就是把 2D 矩阵换成 3D 矩阵、把 2D 卷积换成**体积累积卷积（volumetric convolution）**。哪种表示支持它？答案是体素——几乎只需改一行代码。图形学界并不买账，认为体素预采样慢、质量远不如网格或点云；但「易于类比、改动最小」最终让它成为 3D 深度学习的起点。

### 4.2 3D 数据集的演进：从 1800 个模型到 Objaverse [29:29 - 35:49]

方法之外，数据集同样关键，正如 ImageNet 催生了 AlexNet。前深度学习时代常用 **Princeton Shape Benchmark**：1800 个模型、180 个类别，平均每类仅约 10 个，且几乎没有机器学习。2014 年前的数据集大抵如此，规模顶多上万个模型，摊到众多类别后每类不足百个。随后几个并行工作汇聚成 **ShapeNet**（多由 Stanford 的 Leo Guibas、Silvio Savarese 等主导），共约 **300 万个模型**；日常使用的是其子集 **ShapeNetCore**：约 **5 万个模型、55 个类别**，平均每类约 1000 个，但分布不均，椅子类远多于其他——这也解释了为何早几年论文结果几乎只报 **chairs 和 cars**。

![从物体到部件的层次结构图，展示办公椅的WordNet分类、对称性对齐、部件层级和部件对应关系](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0008_00-34-27.jpg)

该图出自 ShapeNet 论文（Chang et al., arXiv 2015），把物体拆到部件层级：链接 WordNet 分类体系（swivel chair 的上位词 chair > seat > furniture、部件 backrest/seat/base、姊妹词 armchair/barber chair），做对齐与对称性、部件层级（backrest、seat、base、leg、wheel）与部件对应，还标注尺寸 50×45×5 cm、材质 foam/fabric、质量 5 Kg、功能 support 等属性。此后 **Objaverse / Objaverse-XL**（AI2，西雅图）把规模推到约 100 万／1000 万个模型，类别更多、且普遍带纹理、质量更高。

真实扫描数据更难：早期 Redwood 类数据集约 1 万次扫描；Meta 与 Oxford 合作的项目付钱请人用 iPhone 绕物体拍 360° 视频（一次约 1 美元），首版约 **1.9 万段视频**，后续 V2/V3 更大但仍不足 10 万个物体。讲者强调这与 2D 的差距——图像／视频动辄数十亿张，而真实 3D 物体约 10 万量级，是 3D 视觉前进的一大瓶颈。此外还有 Stanford 的 **PartNet**（标注部件语义与可动性，如笔记本电脑可开合）、以及面向 3D 场景的 **ScanNet**（首版约 1500 个房间，第二版约 2000–3000 个房间），场景数据比物体数据又小一个量级。

### 4.3 AI + 几何的任务分类 [35:54 - 38:25]

任务按概率方向分成两类：**生成模型** $P(S)$ 或 $P(S\mid c)$——学习（条件）形状先验、形状生成、补全与几何数据处理（输入图像重建 3D、修补残缺物体）；**判别模型** $P(c\mid S)$——给 3D 形状分类（是椅子还是桌子）。

![AI+Geometry 任务分类幻灯片，区分生成模型 P(S)/P(S|c) 与判别模型 P(c|S)](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0009_00-37-07.jpg)

判别任务有个取巧解法：把 3D 物体渲染成图片，交给很强的图像模型甚至 GPT 去做；但在细胞扫描这类数据稀缺的专业领域仍不奏效。此外还有越来越重要的 **2D 与 3D 联合建模**——2D 数据量大、基础模型强，如何借其「图像／视频该长什么样」的先验让 3D 重建更真实？桥梁正是**可微渲染／神经渲染**：把 3D 渲染成 2D 的过程做成可微（或用网络近似），就能把 2D 先验接进 3D 世界。机器人里的触觉数据、自动驾驶里的 LiDAR／深度数据，也属于多模态融合问题。

## 5. 从多视图 CNN 到 3D 原生生成模型 [38:29 - 45:41]

最早的想法其实绕开 3D 表示：既然 2D 模型在 ImageNet 上很强，就把 3D 物体摆好相机、从多个视角渲染成一组 2D 图，每张过同一个 CNN 提特征，再用池化等方式融合，做图像分类。**Multi-View CNN**（Su et al., ICCV 2015）正是如此——多个视角图像分别输入**共享权重的 CNN_1**，在形状分类上效果很好，还能直接借用 2D 图像模型的大量文献。

![Multi-View CNN 结构图，多个视角图像分别输入共享权重的 CNN1 提取特征](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0010_00-39-23.jpg)

缺点是必须有投影，输入若是很噪的点云，渲染出来很难看。有趣的是这个趋势如今在回潮：当图像／视频基础模型训练数据比 3D 多上千倍乃至百万倍、效果又极强时（讲者提到前一天刚发布的 V3），重新「多依赖一点 2D 基础模型」又变得合理。

于是人们转向**3D 原生方法**：2015 年 Princeton 的一个生成式深度信念网络用 3D 卷积特征、以较低分辨率合成 3D 体素形状，可按语义标签（床、桌等）做条件生成，也能用于分类。讲者团队接着把 **GAN 直接用到 3D 体素**上，生成效果不错；再进一步是 **Visual Object Networks（VON）**（Wu et al., NeurIPS 2016；Zhu et al., NeurIPS 2018）：GAN 不只生成 3D 形状，还经**可微投影**得到深度图／轮廓，再用 CycleGAN 把深度图转成彩色图，于是同时在 3D 形状与 2D 图片上施加对抗损失。

![Visual Object Networks (Geometry + Rendering) 流程图，展示从 shape code 到 2D image 的生成过程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0011_00-43-06.jpg)

由于形状、视角、纹理各有独立隐向量，这类模型具备可控性：换视角、换纹理、做插值，甚至把一辆车的纹理迁到另一辆车的形状上。

体素被诟病「慢且浪费」——大量采样点落在空空间或物体内部、不提供信息。改进方向是**八叉树（octree）**：递归划分空间，在贴近表面处用细体素、在空空间或物体内部用大块体素，从而避开 $O(n^3)$ 的重建代价。同样 GPU 显存下，体素大约只能做到 $64^3$，八叉树可到 $256^3$；**Octree Generating Networks** 用 OGNConv／OGNProp／OGNLoss 逐层细化，在 $32^3$、$64^3$、$128^3$ 等分辨率上逐级生成，也可用于形状生成。

![八叉树生成网络（Octree Generating Networks）的逐层生成流程与特征传播示意图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0012_00-45-30.jpg)

## 6. 点云深度学习：PointNet 与集合距离度量 [45:41 - 51:18]

图形学界更希望直接用点云、网格、样条这些「漂亮」的表示，难点是点这里一个那里一个，怎么在上面做卷积？**PointNet**（Stanford，Leo Guibas 团队）是处理点云的重要工作，它要求网络满足两点：**置换不变性**（点无序，把某点叫 point 1 还是 point 2，输出应相同，不像图像有「左上到右下」的固定顺序）与**采样不变性**（兔子头部采 10 点、尾部 5 点，与反过来，输出也应相同）。

核心想法简单得出奇：先对每个点算嵌入（类似图像里各窗口的特征），再用一个**对称函数**把所有点的嵌入聚合起来——按维取 max、或求和都行——只要 $g$ 对称，整体就对称：

$$f(x_1,x_2,\ldots,x_n)=\gamma\circ g\big(h(x_1),\ldots,h(x_n)\big)$$

![PointNet网络架构示意图，展示了对称函数构造原理及h、g、γ模块的连接关系](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0013_00-49-05.jpg)

这里 $h$ 是共享 MLP 逐点提特征，$g$ 是对称聚合，$\gamma$ 是后续全连接层，最后接分类（椅子／桌子）。这个原始想法既简单又强大，后来衍生出 PointNet++、以及把点转成图节点、以邻近关系为边的图神经网络等大量改进。

生成任务还需**比较两个点集**的距离（分类用交叉熵即可，体素也能直接对 $100^3$ 网格做交叉熵，但点云不行）。两种常用且可微的度量是：**Chamfer 距离**——对红蓝两个点集，每个红点在蓝集中找最近邻、每个蓝点在红集中找最近邻，最小化这些距离；**Earth Mover's Distance**——在两点集间做二分图一对一匹配，最小化所有配对距离。二者可微，因此能回传梯度去优化生成点云的网络。

## 7. 从参数化映射到深度隐式函数 [51:18 - 59:07]

### 7.1 AtlasNet：用网络学习「2D → 3D」的映射 [51:18 - 54:10]

体素受分辨率束缚、点云无序且给不出光滑曲面，于是有人重新看**样条／参数化曲面**：复杂物体的 $(u,v)\to(x,y,z)$ 函数往往没有闭式解，那就**用神经网络（MLP）来表示这个函数 $f$**——输入两个值 $u,v$，网络输出 3D 空间中的一个点。单一变换难以覆盖整个物体，就学多个小网络，像把一张纸以不同方式折多次再拼起来。**AtlasNet**（CVPR 2018）即为此类。

![AtlasNet结果对比图：输入图像、体素、点云与AtlasNet输出的沙发、柜子、汽车三维重建效果](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0014_00-53-28.jpg)

对比图很清楚：同一张输入图像，体素重建被有限分辨率卡住，点云不再受分辨率限制、细节更多但点无序、没有光滑曲面，而 AtlasNet 学出多片参数化映射，表面明显更平滑。

### 7.2 深度网络本身就是隐式函数 [54:10 - 57:46]

讲者给出一条更本质的论证：图像分类里的深度网络，本质是在学一个把大输入空间（$500\times500$ 像素约 25 万维）映射到极小输出空间（1000 类）的复杂函数，这个函数写不出闭式，所以才要深网。既然如此，**深度网络本身就是一个隐式函数**——为什么不直接用它表示 3D 几何？

![显式与隐式几何表示的分类对比图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0015_00-55-58.jpg)

于是约 2019 年出现一次转向：不再预先把空间查成体素再跑 3D 卷积，而是直接把 $xyz$ 坐标送进网络，让它回答「该点在不在物体内」（一维输出），甚至回答**有符号距离函数（离表面多远）、密度、颜色、radiance**。同年有四篇几乎同时的工作持相同主张（如 Liu et al., *Learning to Infer Implicit Surfaces without 3D Supervision*, NeurIPS 2019）。

![深度隐式函数（Deep Implicit Functions）原理示意图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0016_00-57-18.jpg)

图中对比了各表示的取舍：体素 / 点云「+Topology、−Fidelity」，网格「−Topology、+Fidelity」，而占据场（occupancy field）「+Topology、++Fidelity」；显式表示走投影／光栅化，隐式表面走可微渲染与光线步进式的 field probing。也可以把物体表示成一组小网络各自负责的隐式部件，拼出复杂形状。这一步的关键意义是：查询对象从「几何」扩展到了「外观」——为下一节的 NeRF 铺好了路。

## 8. NeRF：可微体渲染与从 2D 图像学习 [59:07 - 63:46]

**NeRF** 在深度隐式函数之上做了两处改动。其一是输入除了 $xyz$，还加入**相机视线方向** $(\theta,\phi)$，输出也不再只是内外或密度，而是 $(RGB,\sigma)$——密度 $\sigma$ 加上颜色／radiance：

$$(x,y,z,\theta,\phi)\ \xrightarrow{\ F_\theta\ }\ (RGB,\ \sigma)$$

![NeRF原理图：展示网络F_theta将空间点(x,y,z,θ,φ)映射为(RGBσ)，并通过光线采样与颜色损失进行训练](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0018_01-04-39.jpg)

其二是训练信号的来源：以往深度隐式函数需要 3D 形状作监督（有真值告诉你某点内外），NeRF 则要**只从 2D 图像学习**，办法是把计算机图形学里的**体渲染（volume rendering）**做成可微的。对一条光线 $r(t)=o+td$ 采样若干点，网络给出每点的密度（可视为不透明度）与颜色，再沿光线积分：

$$c \approx \sum_i T_i\,\alpha_i\,c_i,\qquad T_i=\prod_{j<i}\left(1-\alpha_j\right)$$

其中 $T_i$ 是「该点之前的光被挡掉多少」即透射率，$\alpha_i$ 是第 $i$ 段对这条光线的贡献权重。这个近似下每个环节都可微，于是可以把渲染结果与真实图像算颜色 $\mathcal{L}_2$ 损失、直接端到端训练。

![体渲染（Volume Rendering）的可微分原理图解，包含光线积分公式与透射率计算](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0017_01-01-03.jpg)

因此 NeRF 并非凭空出现：它深受此前只关注几何的深度隐式函数启发，只是**同时建模几何与外观**，并且**借可微体渲染从 2D 图像而非 3D 形状监督**。讲者团队随后把早期流水线里的体素替换成隐式辐射场，继续沿用 GAN + 可微渲染框架，在保持视角、身份等可控性的同时直接从图像学习，不再受限于椅子、汽车这些有大量 3D 数据的类别，输出明显更真实（第一作者 Eric Chen，主要与 Gordon 组合作）。

## 9. 效率与结构：Gaussian Splatting、层级图网络与新趋势 [63:46 - 71:49]

NeRF 的短板是**慢**：虽然不再预采样后做卷积，但仍要沿光线密集采样、每点都查询网络，和体素一样把大量算力浪费在空空间上（网络在那里只会给出密度 0）。图形学思路再次给出答案：既然点云／网格在空间里是「自由」且高效的，能否既保留隐式表示、又不必固定网格全时段采样？**3D Gaussian Splatting** 的做法是用一组 **3D 高斯 blob** 作为点表示（点不是单点，而是带半径的区域），因为事先知道 blob 在哪，从相机射出光线时只在附近有内容处采样，渲染效率大幅提升。

![完整的质量与效率综合对比图，新增FPS和训练时间(Train)维度的性能分析](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0019_01-07-02.jpg)

幻灯片的质量—效率对比给出了具体数字：渲染质量（PSNR/SSIM，讲者提醒纵轴并非从 0 起、略有误导）上 Gaussian Splatting 与 NeRF 相当；但速度天差地别——FPS 一栏 Instant-NGP 为 9.0、MipNeRF360 仅 0.07，而作者方法 30K 迭代达 137.3、7K 迭代达 167.9；训练时间一栏 MipNeRF360 需 48 小时，作者方法 30K 为 38.3 分钟、7K 仅 6.1 分钟。讲者的口语概括是：NeRF 渲染一张图约 20 秒，Gaussian Splatting 可到每秒约 150 张，约快 1000 倍。

最后两分钟把话题从几何细节移到**结构**：点云、网格、隐式函数主要刻画单个部件的细节，却不直接捕捉物体几何中的**规律性——对称、重复与层级**。以椅子为例，底座、座面、靠背构成层级，各条腿之间要对称、形状一致、位置对齐，否则椅子会倒；场景里床通常靠墙、椅子通常挨着桌子，也存在部件间关系。人们于是用简单几何基元的集合、可组合的隐式函数、乃至**层级图网络**来建模——**StructureNet**（Mo et al., 2019）用图卷积编解码可变度数的节点，`e_graph / e_geo / d_graph / d_geo` 分别处理结构与几何，生成满足这些约束与层级的 3D 椅子。

![形状基元的层级图网络架构图及生成过程演示](/coursenotes/cs231n-deep-learning-for-cv-sp25/l15-3d-vision/kf_0020_01-10-38.jpg)

又因形状里存在重复与 for 循环，也有人把形状写成**程序**、让神经网络生成能合成物体及其部件关系的程序。最新（近一两年）的趋势是：既然大语言模型（如 GPT）对语义和「椅子该满足什么约束」理解得这么好，何不直接让 LLM 输出这类程序，再用隐式函数去补上各部件的具体几何细节？讲者以此作为全讲收束。

## 要点回顾

- 3D 对象含几何、纹理、材质且尺度跨度大，表示方式不像 2D 像素那样统一；选择表示要权衡存储、创建、编辑、渲染、逆渲染与动画，以及与深度学习方法的整合。
- 显式表示直接给点：点云是 $3\times n$ 矩阵、可带法线、常为传感器原始输出但无拓扑；多边形网格加点与面的连接、是图形工业主力、支持细分／简化／正则化；参数化曲面用低维函数映射，如球面 $s(u,v)=r(\cos u\cos v,\sin u\cos v,\sin v)$、环面 $f(u,v)=((2+\cos u)\cos v,(2+\cos u)\sin v,\sin u)$。
- 显式表示易采样、难内外测试；隐式表示以 $f(x,y,z)=0$ 定义表面（球体 $x^2+y^2+z^2-1$），代入 $(3/4,1/2,1/4)$ 得 $-1/8<0$ 即在内部，易内外测试、易做并交差与距离函数混合，却难采样。
- 水平集把隐式函数预查询成 3D 数值网格、边界落在正负相邻处；体素再二值化为 3D 矩阵，因其与像素的类比成为 3D 深度学习的起点（2D 卷积 → 3D 体积累积卷积）。
- 数据集从 Princeton Shape Benchmark（1800 模型／180 类）到 ShapeNet（约 300 万模型，Core 子集 5 万／55 类）、Objaverse(-XL)（百万至千万级）、真实扫描（约 1.9 万段视频、不足 10 万物体）、PartNet 与 ScanNet；与 2D 数十亿图像相比仍有量级差距，早期结果因而集中于 chairs 与 cars。
- 任务分生成模型 $P(S)$/$P(S\mid c)$（形状先验、生成、补全、几何处理）与判别模型 $P(c\mid S)$（分类），以及借可微／神经渲染桥接的 2D–3D 联合建模与多模态融合。
- 方法脉络：Multi-View CNN（共享 CNN_1 多视图融合）→ 3D 原生生成网络与 3D-GAN / Visual Object Networks（可微投影 + CycleGAN，形状／视角／纹理隐向量可控）→ 八叉树（避开 $O(n^3)$，体素 $64^3$ 提到 $256^3$）。
- PointNet 以「共享 MLP + 对称函数」$f=\gamma\circ g(h(x_1),\ldots,h(x_n))$ 保证置换与采样不变性；点云生成用可微的 Chamfer 距离与 Earth Mover's Distance 度量。
- AtlasNet 用 MLP 学 $(u,v)\to$ 3D 的参数化映射、多片拼出光滑曲面；约 2019 年转向「深度网络即隐式函数」，直接查询 $xyz$ 得内外／SDF／密度／颜色（同年约四篇工作）。
- NeRF 以 $F_\theta:(x,y,z,\theta,\phi)\mapsto(RGB,\sigma)$ 并用可微体渲染 $c\approx\sum_i T_i\alpha_i c_i,\ T_i=\prod_{j<i}(1-\alpha_j)$ 从 2D 图像训练；Gaussian Splatting 用 3D 高斯 blob 只在有内容处采样，质量相当却快约 1000 倍；StructureNet 等则用层级图网络与程序捕捉对称、重复与层级，最新趋势是让 LLM 输出形状程序。
