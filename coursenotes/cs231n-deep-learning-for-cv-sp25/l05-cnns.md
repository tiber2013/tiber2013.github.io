# CS231n Spring 2025 · Lecture 5 用卷积神经网络做图像分类：卷积层、池化层与平移等变性

**核心结论**：本讲由新登场的讲师 Justin 主讲，标志课程从「深度学习基础」板块转入「感知与理解视觉世界」板块。核心论点是：既然深度学习已经给出「张量进、张量出 + 计算图 + 损失函数 + 反向传播」这一通用配方，卷积神经网络只是在这张计算图里新增两类算子——卷积层与池化层——以便尊重图像的二维空间结构，而不必再把像素拉平成一维向量。卷积层把全连接层的「全局模板匹配」改成「小滤波器在图像上滑动的局部模板匹配」，滤波器数值由梯度下降学出、尺寸与数量由人作为架构超参数设定；堆叠卷积必须插入非线性，否则两层线性卷积等价于一层。空间维度由 $W-K+1+2P$、$\frac{W-K+2P}{S}+1$ 等公式控制，padding 保持尺寸、stride 让有效感受野随深度指数增长，池化则是几乎零成本的下采样。卷积与池化共同满足的平移等变性，从数学上刻画了「特征只应取决于内容、而非内容的绝对位置」这一图像先验。

![CS231n课程大纲概览，列出四大模块及对应讲次范围](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0001_00-01-14.jpg)

四大板块为：Deep Learning Basics（Lecture 2–4）、Perceiving and Understanding the Visual World（Lecture 5–12）、Generative and Interactive Visual Intelligence（Lecture 13–16）、Human-Centered Applications and Implications（Lecture 17–18）。在这个拐点回望，前四讲的链条是：先用线性分类器把图像分类形式化为「输入像素张量 → 输出各类别分数张量」，其中 $s=f(x;W)=Wx$；再用损失函数衡量某组权重 $W$ 的好坏，分类常用 Softmax 损失 $L_i=-\log\frac{e^{s_{y_i}}}{\sum_j e^{s_j}}$ 以及 SVM（Hinge）损失，总损失 $L=\frac{1}{N}\sum_i L_i+R(W)$；接着用优化在权重空间里「滑下损失曲面」，常用 SGD + Momentum、RMSProp、Adam——讲者特意提到，就在昨天 ICLR 2025 把「时间检验奖（test of time award）」颁给了 2015 年发表于 ICLR 的 Adam 论文。

![损失函数回顾：Softmax交叉熵公式及包含正则化项的总损失计算流程图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0002_00-03-24.jpg)

线性分类器的两大缺陷导出了神经网络：从视觉观点看，$W$ 的每一行就是一整幅类别模板，每类只能压缩进一张模板（学到的 car 模板像一团红色，但车完全可以是蓝的、紫的、绿的）；从几何观点看，线性分类器只是用超平面切分高维空间，没有理由假设各类别真的线性可分。于是把单个权重矩阵换成两个矩阵加中间非线性，$f=Wx$ 变为 $f=W_2\max(0,W_1x)$，表征能力大幅提升。

![神经网络回顾：线性评分函数与两层神经网络的架构示意图及维度标注](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0003_00-06-53.jpg)

有了模型与损失，就要算 loss 对所有参数的梯度，这靠**计算图（computational graph）**：图中每个节点是一个函数原语（矩阵乘、ReLU 等），数据从左侧的输入与权重前向流到右侧的 loss，再反向从右到左遍历求梯度。反向传播的威力在于把全局问题转成局部问题——每个节点只需在 forward 时由输入算输出、在 backward 时接收 upstream gradient 并算出 downstream gradient，完全不必关心梯度从哪来、自己处在多大的图里；只要所有节点遵守这套局部 API，就能拼成任意复杂的计算图，梯度「转动曲柄就自动得到」。

![向量反向传播示意图，展示局部梯度、雅可比矩阵与上下游梯度的关系](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0004_00-10-11.jpg)

推广到张量时有一条易记规则：输入是张量、输出是张量，**上游梯度 $\partial L/\partial(\text{output})$ 与输出同形，下游梯度与输入同形**——因为 loss 是标量，梯度就是「单独微调张量中每个元素，loss 会变化多少」。于是得到几乎万能的配方：把问题编码成张量 → 写计算图由输入张量算输出张量 → 收集输入输出张量数据集 → 写损失函数 → 用梯度下降与反向传播优化。图像分类、图像生成、大语言模型，凡是训练神经网络，基本都是这个公式或其变体。

## 2. 图像分类：从原始像素到特征表示 [13:50 - 21:05]

重新审视本讲的核心任务：给定一张猫图，从预先定义好的标签集合 $\{dog,cat,truck,plane,\dots\}$ 里预测一个类别。线性分类器与全连接 MLP 某种意义上已经能「解」这个问题，但它们直接工作在**像素空间**——$f(x)=Wx$ 里的 $x$ 就是图像所有像素的字面数值。

![图像分类任务定义：输入猫的图片，从给定标签集中输出预测类别](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0005_00-13-51.jpg)

在神经网络「拯救我们于繁琐」之前的 2000 年代至 2010/2011 年前后，另一种主流做法是 **特征表示（feature representations）**：由人类设计者先定义一个函数，把原始像素转换成我们认为更有意义的高层表征，再把这个表征作为 $f(x)=Wx$ 的输入。

![图像特征提取与线性分类模型示意图：f(x)=Wx](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0006_00-15-53.jpg)

讲者给了两类典型手工特征（并提醒它们大约十年前就已被淘汰，只需了解风味）：**颜色直方图（color histogram）**把颜色空间离散成若干桶，统计落入每个桶的像素数，只反映颜色分布、彻底破坏空间结构（红色在左下角还是右上角，在这种特征下看起来一样，适合判断苹果熟不熟这类问题）；**方向梯度直方图（Histogram of Oriented Gradients, HoG）**恰好相反，丢掉颜色、只编码每个局部区域边缘的主方向（青蛙的对角结构、眼睛周围的圆形结构会被提取出来）。当年常见的做法是把多种特征**拼接**成一个大特征向量，再在上面接任意分类器。

![手工特征提取与卷积神经网络（AlexNet）架构对比图，展示两者均输出10维类别分数](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0007_00-19-17.jpg)

把「特征提取器 + 学到的线性分类器」（System A）与「端到端神经网络」（System B）并排看，二者其实都是输入原始像素、输出类别分数，真正的差别在于**哪部分由人设计、哪部分由梯度下降学出**：前者只有顶部分类器是从数据里学的，特征提取往往是复杂的 C / Matlab 代码；后者的直觉是「梯度下降大概是比你我更好的程序员，海量数据大概比你更懂这个问题」，于是从像素到最终分数的每一部分都由训练数据经梯度下降共同调优。人可能凭错直觉漏掉重要线索、或根本写不出完美的特征提取器，而数据与算力往往能做得更好——这套端到端范式在过去十几年里反复胜出。

但这不意味着人不再需要设计：设计网络与设计特征提取器不同，人定义的是**一整类函数**（由计算图的结构、算子序列、每阶段矩阵尺寸界定），并把权重留给数据去学；架构、算子序列、各层形状仍由人决定。

## 3. CNN 的动机、结构与历史 [21:05 - 30:28]

到目前为止我们只会把像素**拉平（flatten）**成一个大向量，做矩阵乘、ReLU、再矩阵乘、再 ReLU。这有个大问题：图像本质上是二维（甚至带通道的三维）对象，二维空间结构对内容至关重要，拉平向量等于在架构设计里无视了这一先验。于是需要能更好尊重二维结构的新算子，这便是卷积神经网络（CNN / ConvNet）：由线性层、非线性、**卷积层**、**池化层**等拼成，输入原始像素、输出预测分数。其典型结构是：网络主体（body）为卷积、池化、非线性交错的序列，可视为在提取图像的特征表示；顶部再接一层或多层全连接层作为 MLP 分类器；**整个系统端到端由梯度下降最小化训练损失来调优**。

![卷积神经网络（CNN）经典结构示意图，展示输入、卷积、下采样及全连接层流程](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0008_00-23-22.jpg)

历史线索：屏幕上这张经典结构图出自 Yann LeCun、Léon Bottou 等人 **1998 年**用于数字分类的工作，当时没有 GPU/TPU、训练昂贵，但网络架构与 2010 年代所用的已很相似；到 **2012 年 AlexNet**（Krizhevsky, Sutskever, Hinton, *ImageNet Classification with Deep Convolutional Neural Networks*, NIPS 2012）出现，架构仍是卷积层 + 全连接层，只是更大、层数更多、单元更多，靠 GPU 算力与 ImageNet 数据真正起飞。约 **2012–2020 年 ConvNet 几乎统治了所有视觉任务**：检测（给所有物体画框并标类别）、分割（给每个像素独立标类别）、图像描述（image captioning，图像→自然语言）、乃至文生图（text-to-image generation）最早的成熟方案也都建在卷积网络上。

![展示文本到图像生成（Text-to-Image Generation）能力的幻灯片，包含五个具体的生成示例及其对应的提示词。](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0009_00-26-53.jpg)

课件展示的文生图例子引用 Rombach 等人的 *High-Resolution Image Synthesis with Latent Diffusion Models*（CVPR 2022），提示词包括「毕加索风格的僵尸」「半鼠半章鱼」「吃汉堡的松鼠」「水彩画、长得像章鱼的椅子」「印着 I love generative models! 的 T 恤」等。卷积网络重要到本课程 2015 年的初版干脆叫 *Convolutional Neural Networks for Visual Recognition*，当时「卷积网络」几乎就是计算机视觉的同义词。

![卷积神经网络（ConvNet）特征图可视化示意图，展示了从输入图像到最终分类输出的层级变化。](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0010_00-27-53.jpg)

但领域在演进：2020 年之后让 CNN 让位的不是疫情而是 **Transformer**。它 2017 年提出后先在 NLP 里处理文本，2021 年一篇重要论文把几乎相同的架构直接用于图像，此后很多原本用 CNN 的任务换成 Transformer、其余不变就能得到更好性能，且更易于随数据与算力扩展（Lecture 8 详讲）。讲者仍列出学习 CNN 的四条理由：历史意义重大；实践中仍大量使用；能建立「什么对图像重要」的直觉；而且 CNN 并未彻底消亡，当下常构建卷积与 Transformer 混用的 **hybrid systems**。

## 4. 从全连接到卷积层：模板匹配视角 [30:28 - 36:27]

先看全连接层的内部结构：把 $32\times32\times3$ 图像（两个空间维 32、32，加 RGB 三通道）拉平成 3072 维向量，乘以 $3072\times10$ 的权重矩阵，得到 10 个类别分数。输出的每个元素都是「权重矩阵某一行」与「整个输入向量」的**内积（dot product）**；而内积在两向量同向时大、正交时为零，本质是一种**模板匹配（template match）**。因此全连接层可理解为一组与输入同尺寸的全局模板。

![卷积层输入图像维度示意图，展示32x32x3图像的height、width和depth结构](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0011_00-32-54.jpg)

卷积层的推广很自然：仍是模板匹配、仍学一组滤波器（filter bank），但滤波器不再覆盖整幅输入，而只看一个局部小块，并且**保持图像的三维空间结构**。具体地，输入维持为三维张量（3 通道 / depth、32 width、32 height），一个滤波器是一张 tiny 低分辨率子图，例如 $5\times5\times3$——通道数必须等于输入通道数，只有空间尺寸变小。把这个滤波器在图像上到处滑动（convolve / slide），每到一处就与对应的 $5\times5\times3$ 图像块做内积，得到一个标量，表示该局部块与这个模板的匹配程度；把所有位置的分数收成一张二维平面，即**激活图（activation map）/ 响应平面**。

![单个绿色滤波器在图像上滑动卷积的过程，生成28x28激活图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0012_00-35-10.jpg)

再加第二个（绿色）$5\times5\times3$ 滤波器，重复同样的滑动得到第二张响应平面。深度学习要的就是更多滤波器：取 6 个滤波器、每个 $3\times5\times5$，可收成一个四维张量 $6\times3\times5\times5$（首维 6 是滤波器个数）；6 张 $28\times28$ 激活图堆叠起来，输出就是 $6\times28\times28$——6 是通道维，$28\times28$ 是空间维（32 − 5 + 1 = 28）。

![使用6个滤波器进行卷积的完整流程，堆叠生成6x28x28的输出图像](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0013_00-36-21.jpg)

## 5. 卷积层的工程细节：偏置、批模式、参数与超参数 [36:27 - 43:18]

与线性层「每行一个标量偏置」对应，卷积层通常**每个滤波器配一个标量偏置**，本例即 6 维 bias 向量；每个偏置广播（broadcast）到对应激活图的整个空间维，只服务于它那一个滤波器。滤波器数值不由人定义，而是随机初始化后靠梯度下降与反向传播从数据里学出——这正是卷积层能力的来源：我们只定义一个计算代价较高的算子，期待它被数据与算力「填满」。

课堂上几个关键问答：**滤波器尺寸（如 5）是架构超参数**，通常靠交叉验证设定；单层卷积一般固定一个滤波器尺寸，因为便于写高效 GPU kernel，若想要多尺寸（下讲会讲 Inception）应把不同尺寸的卷积层在计算图里拼接出来，而不是让单层支持混合尺寸。必须区分**参数与超参数**：滤波器数量、输出通道数、滤波器尺寸决定张量形状，是训练前一次性设定的超参数；滤波器张量内部的具体数值是训练中由梯度下降优化的参数（先随机初始化、再随优化浮动）。反向传播永远算的是 loss 对网络内部量（这里是卷积滤波器每个标量权重）的梯度——「微调这个标量，loss 会变多少」。训练循环始终是 `while True`：取一个 batch → forward → 算 loss → backward 求梯度 → optimizer 迈一步，每一步都会改动滤波器。滤波器之所以能学到不同特征，全靠**随机初始化打破对称性**：若初始化成完全相同，loss 与回传梯度都相同，它们会永远保持一致。

![卷积层（Convolution Layer）的数据流与维度变化示意图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0014_00-41-29.jpg)

实践中卷积层几乎总在 **batched 模式**下工作，一切都变成四维张量：输入为一批图像（如 $2\times3\times32\times32$）、滤波器为一批三维块（$6\times3\times5\times5$）、输出为一批结果（$2\times6\times28\times28$，每张图一个三维激活堆叠），另有 6 维 bias 向量。一般形式可记成：

```python
# 卷积层的形状记账（本讲给出的通用形式）
# input :  N     x C_in  x H  x W
# weight:  C_out x C_in  x KW x KH
# output:  N     x C_out x H' x W'
# 其中 KW / KH 为 kernel width / height，C_out 为滤波器个数（输出通道数）
```

于是卷积网络无非是把许多卷积算子前后堆叠起来的计算图。

## 6. 堆叠卷积、非线性与滤波器可视化 [43:19 - 49:22]

一个简单的 ConvNet：从 $3\times32\times32$ 出发，第一层 6 个 $5\times5\times3$ 滤波器得到 $6\times28\times28$（空间尺寸因卷积略缩），第二层换成 10 个 $5\times5\times6$ 滤波器——其中的 6 必须匹配上一层输出的通道维，10 决定下一层的输出通道数。

![卷积神经网络结构图，展示输入特征图经过多层CONV和ReLU后的尺寸变化及滤波器参数](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0015_00-45-22.jpg)

这里藏着一个必须修掉的 bug：**「everything's linear」**。卷积是内积、是线性算子，两个线性算子复合仍是线性算子，所以两个卷积层直接叠在一起，表征能力与单个卷积层相同。修复办法与多层网络那次完全一样——**在卷积层之间插入非线性激活函数**。因此 ConvNet 一般是「卷积层 + 非线性 + 其他层」的堆叠。

卷积滤波器可以类比线性分类器的模板来可视化，只不过每片滤波器只是输入图像的一个小局部块。把在 ImageNet 上训练好的 **AlexNet 第一层滤波器**直接画成 RGB 小图，会发现几乎所有卷积网络在合理任务上学到的第一层滤波器都长这样，分两类：一类找**颜色**，尤其对立色（如绿—红对比、粉色/绿色色块）；一类找**空间结构**，如垂直边缘、水平边缘、对角边缘。高层滤波器学到更大的空间结构，可视化更麻烦（讲者展示的图中每行是一个滤波器、每列是该滤波器强响应的输入图块）：第六层某滤波器似乎响应眼睛，有的响应文字片段，有的响应车轮 / 圆形 / 上半圆。这一切都由梯度下降在大规模数据上驱动，没有人坐下来手画这些滤波器；甚至还能反过来用梯度下降从滤波器响应重构原图（后面几讲会讲）。

## 7. 空间维度、padding、stride 与感受野 [49:22 - 55:54]

把卷积示意图旋转 90°、丢掉通道维来看空间尺寸：$7\times7$ 输入配 $3\times3$ 卷积核，滤波器能放下 5 个位置，故输出 $5\times5$；一般地
$$\text{Output}=W-K+1$$

![卷积空间维度计算幻灯片，展示7x7输入加3x3滤波器得5x5输出的网格示例及通用公式](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0017_00-52-11.jpg)

问题是特征图会逐层缩小。常用的偷懒办法是 **padding**：在真实输入周围补上一圈虚拟数据（补零），输出尺寸因此加上 $2P$：
$$\text{Output}=W-K+1+2P$$
常见设置是取 $K$ 为奇数、$P=(K-1)/2$，这样卷积前后空间尺寸不变（如 $3\times3$ 配 $P=1$）。讲者提醒，从信号处理角度看补零会在边界引入怪异效应，但实践中大多情况尚可接受。

接着是 **感受野（receptive field）**：单个卷积的每个输出只看与卷积核同尺寸的一小块输入；当多个卷积层堆叠时，末层每个元素依赖前一层的局部区域，后者又依赖更前一层的局部区域，于是「原始图像中有机会影响某个下游激活的像素数」——**有效感受野（effective receptive field）**——随卷积层数**线性**增长。但分类决策最终希望聚合全图信息，线性增长需要很多层，于是引入 **stride**：不再把滤波器放在每个位置，而是隔几个放一次。$7\times7$ 输入、$3\times3$ 核、stride 2 得 $3\times3$ 输出；通用公式为
$$\text{Output}=\frac{W-K+2P}{S}+1$$
其中「+1」来自栅栏桩（fence post）计数。步长卷积相当于在网络内部**下采样**：每层把特征图尺寸约除以 2，堆叠起来后有效感受野随网络深度**指数**增长，于是用很少的层就能覆盖整幅输入。

## 8. 完整卷积计算示例：尺寸、参数量与计算量 [55:54 - 59:29]

把公式走一遍：输入 volume $3\times32\times32$，10 个 $5\times5$ 滤波器，stride 1、pad 2，输出 volume 为 $10\times32\times32$——10 是输出通道数必须与滤波器数一致，空间 32 来自 $\frac{32-5+2\times2}{1}+1=32$（$K=5$ 为奇数、$P=2=(K-1)/2$，尺寸保持不变）。

![卷积层参数计算示例，展示输入输出体积尺寸及可学习参数问题](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0018_00-57-06.jpg)

**可学习参数量 = 760**：每个滤波器是 $3\times5\times5=75$ 个权重再加 1 个偏置，共 76；乘 10 个滤波器得 760。**计算量**用输出元素数 × 每个元素的点积长度估算：输出 $10\times32\times32\approx10{,}000$ 个元素，每个都由 $3\times5\times5=75$ 元素的点积算出，约需 $768{,}000$ 次浮点乘加（multiply-add / FLOPs）。卷积层还有一页「一行总结」，把全部超参数与公式汇总，并对应到 PyTorch 的 `Conv2d`；另有 groups、dilation 两个本讲未展开的超参数（dilation 如今用得不多，groups 仍常见）。此外卷积不局限于二维图像：还有在 1D 信号上滑动滤波器的 **1D 卷积**，以及在三维空间中滑动三维滤波器的 **3D 卷积**。

## 9. 池化层、架构模式与平移等变性 [59:29 - 67:57]

**池化（pooling）**是另一种下采样手段，动机是：下采样能更快构建感受野，但卷积承担了 ConvNet 里绝大部分 FLOPs，而池化几乎不花算力。给定三维特征张量（如 $64\times224\times224$，即 64 个通道、每片是空间平面图），池化把每张特征平面单独取出、独立下采样，再按原通道数堆叠回去——**通道数不变，空间尺寸变小**。

![池化层（Pooling）的输入输出尺寸公式与超参数总结幻灯片](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0019_01-04-39.jpg)

下采样方式本身是超参数，最常用 **max pooling**：把单个 depth slice 划成不重叠的 $2\times2$ 块（沿用卷积术语即 kernel size $2\times2$、stride 2），每块取最大值（如 6, 8, 3, 4 → 8）；此外还有 average pooling、anti-alias downpooling。池化的超参数与卷积类似，另多一个「pooling function」，输出尺寸为 $H'=\frac{H-K}{S}+1$、$W'=\frac{W-K}{S}+1$，且**没有可学习参数**；最常见设置是 max、$K=2$、$S=2$，正好 2 倍下采样（如 $224\times224\times64\to112\times112\times64$）。问答要点：池化通常**不用 padding**（数学上并无禁止，但 max pooling 加 padding 近似于 ReLU，若已用 ReLU 就冗余）；stride 等参数一般也不怎么调，「整体缩小一半」是压倒性的默认选择。

![卷积神经网络四大组件（全连接、激活、卷积、池化）的可视化对比示意图](/coursenotes/cs231n-deep-learning-for-cv-sp25/l05-cnns/kf_0020_01-07-49.jpg)

输入图像必须同尺寸，否则批处理会出问题；解决办法包括把所有图 resize 到同尺寸、补零 pad 成同尺寸（保留比例而不扭曲），或在较复杂的训练系统里做 **aspect ratio bucketing**（按宽高比分桶，每个 batch 内分辨率与宽高比一致，不同迭代可取不同桶）。池化通常与卷积交错，一个原型化的 ConvNet 模式是 `conv pool conv conv pool conv conv pool fc fc`。是否自带非线性取决于类型：**max pooling 本身是非线性**（此时该卷积后未必再需要 ReLU），**average pooling 是线性的**（仍应加 ReLU）。

最后讲 **平移等变性（translation equivariance）**，作为「尊重图像二维结构」的数学刻画：对图像「先做卷积/池化、再平移特征图」与「先平移图像、再做卷积/池化」，在忽略边界条件、无限大图像等技术前提下结果相同，即平移与卷积/池化的顺序可交换（数学家会称之为交换图 commutative diagram）。它烘焙进一条关于图像的重要直觉：提取出的特征应当只取决于**内容**，而不取决于该内容出现在图像中的绝对位置——人眼往左看或往右看，人和长椅都应被同样地处理。讲者强调这只是个有趣的数学性质，并非要在网络里真的去做平移；把这种先验写进算子设计，而非像开篇那样写进人工特征提取器，正是本讲一路走来的立意。下一讲将把这些算子拼成完整的 CNN 架构。

## 要点回顾

- 本讲由 Justin 主讲，课程从 Deep Learning Basics（L2–4）转入 Perceiving and Understanding the Visual World（L5–12）；通用配方是「张量 + 计算图 + 损失函数 + 反向传播」，图像生成、大语言模型亦不例外。
- 前四讲链条：线性分类器 $f=Wx$ → Softmax/SVM 损失 $L=\frac{1}{N}\sum L_i+R(W)$ → SGD/Momentum/RMSProp/Adam 优化；线性分类器受「每类一张模板」与「只能用超平面切分」两大限制，故升级为 $f=W_2\max(0,W_1x)$。
- 反向传播把全局求导转成局部问题：节点只需 forward 算输出、backward 收上游梯度算下游梯度；上游梯度与输出同形、下游梯度与输入同形。
- 手工特征（颜色直方图只看颜色破坏空间结构、HoG 只看边缘方向丢了颜色、多种特征拼接）与端到端学习的差别在于哪部分由人设计；「梯度下降是比人更好的程序员」，但架构、算子序列、形状仍由人定。
- CNN 由线性层、非线性、卷积层、池化层组成：body 提特征、顶部全连接分类、整体端到端训练；历史从 LeCun 等 1998 → AlexNet 2012 → 2012–2020 统治检测/分割/描述/文生图 → 2020 后被 Transformer 分流，但 hybrid 系统仍常用卷积。
- 卷积层保留三维结构：全连接是全局模板匹配，卷积是 $5\times5\times3$ 小滤波器滑动做局部内积得激活图；6 个 $3\times5\times5$ 滤波器 → 输出 $6\times28\times28$；每滤波器一个 bias，滤波器由梯度下降学、尺寸与数量是超参数。
- 参数与超参数要分清；随机初始化打破对称性使滤波器学到不同特征；训练循环 forward→loss→backward→step 每步改滤波器；batched 一般形式为 $N\times C_{in}\times H\times W$ / $C_{out}\times C_{in}\times K_W\times K_H$ / $N\times C_{out}\times H'\times W'$。
- 两层卷积直接叠加因线性而等价于一层，必须插入激活函数；AlexNet 第一层滤波器可视化为对立色/色块与垂直、水平、对角边缘，高层响应眼睛、文字、车轮等更大结构。
- 空间维度公式 $W-K+1$、$W-K+1+2P$、$\frac{W-K+2P}{S}+1$，$P=(K-1)/2$ 保持尺寸；有效感受野随深度线性增长，stride 下采样使其指数增长。
- 示例 $3\times32\times32$ + 10 个 $5\times5$ stride1 pad2 → $10\times32\times32$，参数 760（=(75+1)×10）、约 768,000 次乘加；池化（常 max、2×2、stride2）无参数、廉价下采样，公式 $H'=\frac{H-K}{S}+1$，通常不用 padding；卷积与池化满足平移等变性，特征只取决于内容而非绝对位置。
