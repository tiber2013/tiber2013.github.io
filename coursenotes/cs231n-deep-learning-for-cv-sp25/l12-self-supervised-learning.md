# 第 12 讲 · 自监督学习：从代理任务到对比学习

> **Stanford CS231n 计算机视觉 · L12** ｜ 讲者：Stanford CS231n 课程团队 ｜ 75 分钟 ｜ [原视频](https://www.youtube.com/watch?v=4howBU7THbM)

> 课件版本：2026 春季 ｜ 视频版本：2025 春季。2026 课件新增或调整的内容集中在文末「2026 课件更新」一节。

## 核心结论

这一讲要解决的是标注瓶颈：训练大规模视觉模型需要海量人工标签，而 **self-supervised learning** 用数据自身构造监督信号。基本配方是先在一个无标签大数据集上定义一个 **pretext task**（旋转预测、拼图、修复、着色、遮挡重建），训练出 **encoder**，再把它迁移到只有少量标签的 **downstream task** 上。早期的图像变换类代理任务依赖“视觉常识”，学到的特征有针对性但不一定通用；2021 年的 **MAE** 用高比例遮挡把重建预训练做到大规模，成为当下常用的选择。后半段转向 **contrastive learning**：把同一图像的不同视角在表示空间拉近、把其他样本推远，其损失 **InfoNCE** 本质是一个 N 路 softmax 分类，并给出互信息下界；**SimCLR** 与 **MoCo** 分别用超大 batch 和动量队列解决负样本数量问题。

## 回顾：像素空间不够，特征是更好的表示 [00:05 - 04:44]

上一讲是 GPU 与大规模分布式训练；更早，课程覆盖了分类、语义分割、目标检测、实例分割这些任务，以及如何可视化和理解模型。今天回到其中一条线索：**representation**。

课程早期做过像素空间的 kNN：给定测试图，按 L2 距离找最像的训练图，效率不高。换成网络中间层的特征就完全不同——把图像送进 AlexNet，取 4096 维的 **feature vector**，再在特征空间做 L2 最近邻，找回来的往往是同类物体。视频里还提到 features、embeddings、latent space 这些叫法，说的都是同一件事：网络学到的、比原始像素更有语义的表示。

![对比像素空间与特征空间的最近邻检索效果，并展示4096维特征向量提取架构](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0002_00-01-49.jpg)

有了好特征，类别标签可以由一个简单的线性模型给出。问题是训练这样的网络需要大量**人工标注**：分类要给每张图打标签，分割要逐像素标注，规模一大就难以为继。

![AlexNet卷积神经网络架构图及大规模训练数据需求问题](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0003_00-04-15.jpg)

于是本讲的问题被提出来：能不能不用海量人工标签，也训练出好的特征？

## 自监督学习的框架：pretext task 与 downstream task [04:44 - 08:37]

假设是：给定一个没有标签的大数据集，用一个 **pretext task**（代理任务）作为目标函数训练网络，就能得到好的特征；再把这个 encoder 迁移到只有少量标签的 **downstream task**（下游任务）上。

流程是一条链：无标签数据集 → **encoder** → learned representation → **decoder / classifier / regressor** → 由数据自动生成的标签或输出。监督信号不是人写的，而是从数据本身构造出来的。第二个模块叫 decoder、classifier 还是 regressor，取决于代理任务怎么定义。

![自监督学习预训练任务流程图，展示编码器与解码器/分类器从无标签数据自动生成标签](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0004_00-06-34.jpg)

预训练完成后，把与代理任务相关的那部分去掉，接上一层或几层全连接，用下游任务的少量标签训练这个头。讲者强调，通常希望这个头越浅越好：如果特征足够好，就不需要在下游任务上再训练很多东西。

这个范式不只属于视觉。**GPT-4** 这类大语言模型主要用原始文本训练；语音、机器人和强化学习也在用同样的思路。自动驾驶公司之所以能在湾区大量收集数据，正是因为不需要逐条标注也能拿来训练。

## 代理任务的设计与评估 [08:37 - 15:28]

代理任务没有唯一答案，但有两个门槛：一要足够通用，能学到有用的特征；二要能自动生成标签。视频给了四个经典例子：**image completion**（遮住一部分，预测缺失部分）、**rotation prediction**（旋转图像，预测角度）、**jigsaw puzzle**（打乱图块，预测顺序）、**colorization**（给灰度图上色）。

![自监督预训练任务示例：图像补全、旋转预测、拼图游戏和着色](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0005_00-09-11.jpg)

怎么判断一个自监督方法好不好？可以从几个层面看：代理任务本身的表现；表示质量（在冻结特征上训练线性分类器、做聚类、用 t-SNE 降维看可分性）；鲁棒性与泛化；计算效率。但最重要的是**下游任务的表现**，因为定义代理任务的目的就是服务于下游。

![自监督学习方法评估流程图：从无标签数据学习特征提取器](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0006_00-12-27.jpg)

以旋转任务为例：卷积层提取特征，后接全连接层预测旋转角度；预训练后去掉这部分，换成一层或几层分类器预测物体类别，只训练新加的部分。这也是后面反复出现的 **linear probing** 思想的雏形。

![今日课程议程：图像变换预训练任务与对比表示学习](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0007_00-15-01.jpg)

议程把课程分成两半：前半是图像变换类代理任务，包括后来的 **MAE**；后半是对比表示学习，从直觉与公式到 **SimCLR**、**MoCo**、**CPC** 和 **DINO**。

## 旋转预测：用视觉常识做监督 [15:28 - 23:00]

旋转任务的假设是：模型只有具备 **visual commonsense**——知道物体正常摆放时该是什么样子——才能判断图像被旋转了多少。能判断旋转，说明它已经把整张图概括成了有用的特征。

Gidaris 等人 2018 年的做法是把整张图分别旋转 $0^\circ$、$90^\circ$、$180^\circ$、$270^\circ$，让网络预测四个类别之一，于是问题变成 4 路分类。

![旋转预测预训练任务的流程图，展示输入图像经过四种旋转生成四个样本并进行4分类](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0008_00-16-47.jpg)

下游评估有两组结果。在 CIFAR-10 的半监督设置里，冻结前两个卷积层，只用一部分标签训练后面的层：预训练模型起点很高，但在这种简单任务上，全监督版本最终能追平。讲者补充，换成更难的任务，不做预训练的模型就很难跟上。

![半监督学习评估结果折线图，对比自监督预训练与监督学习在不同训练样本数下的测试准确率](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0009_00-18-40.jpg)

在 PASCAL VOC 2007 上，微调全部层时 RotNet 的分类 mAP 是 72.97、检测 54.4、分割 39.1；完整 ImageNet 监督预训练对应 79.9、56.8、48.0；随机初始化只有 53.3、43.4、19.8。旋转预训练接近 ImageNet 预训练，远好于随机初始化。

![迁移学习特征在监督学习任务上的性能对比表格，包含分类、检测和分割的mAP/mIoU指标](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0010_00-19-34.jpg)

把特征反投影回图像空间看注意力，可以看到差异：监督模型的注意力更集中，往往只盯住能判别类别的部位（比如眼睛）；自监督模型的注意力覆盖更广，因为它不知道下游任务是什么，必须对图像有更整体的理解。

## 相对位置与拼图：把空间结构变成标签 [23:00 - 26:33]

Doersch 等人 2015 年的任务是预测图块的相对位置：把图像切成 $3\times3$ 网格，以中心块为参照，问某个图块来自其余 8 个位置中的哪一个。这是一个 8 路分类问题。

![预测图像块相对位置的pretext task示意图，展示猫的图片被分割成9个区域并预测相对位置](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0011_00-23-01.jpg)

Noroozi 与 Favaro 2016 年把它推进成拼图：取同样的 9 个图块，随机打乱，让网络预测正确的排列。9 个图块的全排列是 $9! = 362{,}880$ 种，直接做分类不现实；作者预先挑出 64 种差异足够大的排列（很多排列只是交换了一两个图块），把任务变成 64 路分类。他们在相同的迁移设置下对比，拼图方法超过了之前的相对位置方法。

![拼图前置任务流程图：将汽车图像切块打乱后输入AlexNet进行排列预测](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0012_00-24-22.jpg)

## 图像修复：用重建学特征 [26:33 - 31:19]

Inpainting 的思路是遮住图像的一块，让模型补出来。编码器把输入压到特征空间，中间接全连接层，再由解码器还原缺失区域；损失函数直接比较输出与真实图像，本质是一个带遮挡目标的自编码器。

![基于重建的图像修复学习架构图：编码器-解码器结构重建缺失像素](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0013_00-26-58.jpg)

这里的评估比较微妙：修复没有唯一正确答案。只用重建损失训练，输出往往模糊、平滑。Pathak 等人在重建损失之外加了**对抗损失**，让补出来的区域看起来更像真实图像；对抗学习的细节留到下一讲。

重建损失只算在被遮挡的区域上，因此要对 mask 做逐元素相乘：

$$
L_{recon}(x) = \left\| M \odot \left(x - F_\theta\left((1-M)\odot x\right)\right) \right\|_2^2
$$

迁移结果（ImageNet 训练集上预训练，再迁移到 PASCAL VOC）：Context Encoder 用 14 小时预训练得到 56.5 / 44.5 / 30.0，ImageNet 全监督用 3 天得到 78.2 / 56.8 / 48.0，随机初始化只有 53.3 / 43.4 / 19.8。自监督还远不如全监督，但明显好过随机初始化，而预训练时间短得多。

![不同预训练方法在分类、检测和分割任务上的迁移学习性能对比表格](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0014_00-30-36.jpg)

## 着色与 Split-brain Autoencoder [31:19 - 37:09]

计算机视觉默认用 RGB，但 RGB 把亮度与颜色混在一起。**Lab** 色彩空间把亮度 $L$ 与颜色 $a$、$b$ 分开，于是可以定义：给定 $L$ 通道，预测 $a$、$b$ 两个通道。标签本来就在数据里，不需要人工标注。

这个想法可以再对称化。**Split-brain Autoencoder** 训练两个网络：$F_1$ 从亮度预测颜色，$F_2$ 从颜色预测亮度；把两路输出拼回完整图像，用 L2 损失训练。

![Split-brain Autoencoder 架构图：输入 RGB-HHA 图像，分别经 F1 和 F2 预测 HHA 深度通道和 RGB 通道](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0015_00-34-27.jpg)

更一般地，这是**跨通道预测**：给定一组通道预测另一组。例如 RGBD 传感器同时有 RGB 与深度通道，可以让模型从 RGB 预测深度，也可以反过来。下游任务用的是 $F_1$、$F_2$ 拼接后的特征，效果不错，但仍不如有监督预训练。

着色还有一个附带价值：它本身就能用。老照片、老视频没有彩色版本，模型可以替它们上色；课件里那张袋狼（塔斯马尼亚虎）的历史照片，就是着色任务的经典示例。

![图像着色预训练任务示例：展示一张已着色的袋狼（塔斯马尼亚虎）历史照片](/coursenotes/cs231n-deep-learning-for-cv-sp25/l12-self-supervised-learning/kf_0016_00-35-43.jpg)

视频还展示了 Half Dome 的例子——模型不仅给山体上色，还让水中的倒影保持了与实物一致的颜色，说明它从大量数据里学到了“倒影应当反映实物颜色”这样的规律。

## 视频着色：跟踪从着色中涌现 [37:09 - 40:56]

把着色扩展到视频，做法是给定一张已经着色的 **reference frame**，为后续帧上色。要为某个像素取色，必须先找到它在参考帧里的对应位置：用 CNN 提取像素周围的特征，计算目标像素与参考帧所有像素的相似度（也就是 attention），再按 attention 加权平均参考帧的颜色作为输出。损失用数据里已知的真实颜色计算。

如果对每一帧独立着色，同一个人的衬衫可能一会儿红一会儿蓝；引入参考帧的 attention 之后，颜色在时间上保持一致。假设也随之成立：学会给视频上色，就等于学会了在无标签的情况下跟踪区域和物体。

视频还展示了下游用途：用学到的 attention 传播分割 mask、跟踪物体片段，甚至传播人体的关键点。

## 课堂问答：监督信号到底从哪来 [40:56 - 45:41]

有同学问：编码器一开始什么都不知道，它凭什么学会提取特征？讲者的回答是，所有代理任务都在做同一件事——解码、分类或回归出某个输出，再用这个输出与真实值的差异反向传播；梯度穿过 decoder 回到 encoder，encoder 就是在这个过程中被训练出来的。标签来自 decoder 这一侧，这正是需要定义代理任务的原因。

另一个问题是 encoder 和 decoder 是不是同一个网络。答案取决于任务：旋转预测里，卷积层加全连接层可以是一个网络；自编码器里常常是两个网络端到端训练，以便利用中间的表示空间；到 MAE，encoder 与 decoder 甚至不需要对称。

讲者也提醒，这些是自监督学习最早的一批方法，不指望它们解决所有问题。旋转任务本身很有限，但如果模型能判断出 90 度旋转，它至少隐含地理解了物体的正确朝向。

## MAE：把遮挡做到极致 [45:41 - 54:00]

2021 年的 **Masked Autoencoder（MAE）** 也是重建类方法，但比 inpainting 激进得多：随机遮住大部分图块，遮挡比例可以到 50% 甚至 75%，让模型从剩下的一小部分重建整张图。任务越难，模型越必须学到真正的结构，学到的 encoder 也越好。

MAE 的 encoder 沿用 ViT 的做法：把图像切成不重叠的 patch，均匀采样保留 25%，做线性投影并加上位置编码，再送入 transformer。因为 encoder 只处理可见的 patch，它可以做得非常大；高遮挡比例还带来一个副作用——同一张图每次遮挡都不同，相当于免费的数据增强。

decoder 收到可见 patch 的 embedding，加上一个可学习的 **mask token** 填在被遮住的位置，再加上位置编码，然后用 transformer 还原像素。损失只在被遮住的 patch 上计算，用像素空间的 MSE。encoder 与 decoder 是非对称设计，decoder 只负责重建，预训练结束后就丢掉。

在下游使用上有两种方式：**linear probing** 冻结 encoder，只训练一个线性层，用来衡量表示质量；**full fine-tuning** 则连带 encoder 一起微调（全部或部分 transformer block），能发挥模型的上限。

消融实验里，75% 的遮挡比例最好；遮挡方式上随机遮挡优于 block 和 grid；decoder 的深度与宽度、是否在 encoder 里使用 mask token、重建目标、数据增强都会影响结果。当时 MAE 的表现超过了 **DINO** 和 **MoCo v3** 这些对比学习方法。讲者说，如今在原始数据上做预训练，MAE 是很常用的选择。

## 从代理任务到对比学习 [54:00 - 61:00]

代理任务的总结是：它们关注“视觉常识”，迫使模型学习自然图像的结构；我们并不在意代理任务本身的准确率，而在意特征对下游是否有用。问题有两个：每设计一个代理任务都很费劲；学到的表示可能只对那个任务有效，不够通用。

于是有了一个更一般的代理任务。数据增强产生的图像和原图是同一个物体，只是形式不同；数据集里的其他物体则完全不同。能不能定义这样一个目标：同一个物体的表示在特征空间里互相**吸引**（attract），不同物体的表示互相**排斥**（repel）？这就是**对比表示学习**（contrastive representation learning）。

记参考样本为 $x$，同一张图的变换为 $x^+$（positive），批次中的其他样本为 $x^-$（negative）。我们希望

$$
\operatorname{score}\left(f(x), f(x^+)\right) \gg \operatorname{score}\left(f(x), f(x^-)\right)
$$

2018 到 2020 年间涌现了一批方法：**SimCLR**、**MoCo**、**CPC**，以及借鉴了对比思想但不完全是对比学习的 **DINO**。

## InfoNCE：把对比写成 N 路分类 [61:00 - 66:00]

给定一个正样本和 $N-1$ 个负样本，把 score 送进 softmax，就得到

$$
L = -\mathbb{E}_X\left[\log \frac{\exp\left(s(f(x), f(x^+))\right)}{\exp\left(s(f(x), f(x^+))\right) + \sum_{j=1}^{N-1}\exp\left(s(f(x), f(x_j^-))\right)}\right]
$$

这个式子和多分类的交叉熵完全同构：把正样本当成正确类别，把 $N-1$ 个负样本当成其他类别，任务就是“从 N 个候选里找出正样本”。它被称为 **InfoNCE**（information noise contrastive estimation）。

InfoNCE 还有一层信息论解释：它的负值是 $f(x)$ 与 $f(x^+)$ 之间互信息的一个下界，

$$
MI\left[f(x), f(x^+)\right] - \log N \geq -L
$$

所以最小化 InfoNCE 就是在最大化正样本对之间的互信息。负样本数 $N$ 越大，这个下界越紧，这也是对比学习需要大 batch 的理论理由。

## SimCLR：简单框架与两个设计选择 [66:00 - 71:20]

**SimCLR** 的结构很简单：同一张图做两次随机数据增强，得到一对正样本；两者分别经过 encoder $f$ 和投影头 $g$，在 $z$ 空间用余弦相似度作为 score，用 InfoNCE 计算损失。一个 batch 有 $N$ 张图，增强后变成 $2N$ 个样本；每个样本的正样本是它的“孪生兄弟”，其余 $2N-2$ 个都是负样本。

数据增强的选择很关键：随机裁剪、颜色扰动、模糊等。作业 3 里有一道 SimCLR 的题目，但公式与课上讲的略有不同，讲者提醒按作业说明来做。

结果上，SimCLR 不用任何标签，只在线性分类器上训练，就超过了之前的方法，接近全监督学习；代价是需要更大的网络，因为它学的是更通用的特征。

两个设计选择值得记住。第一是**投影头**：对比损失会迫使表示对数据变换不变，这可能丢掉对下游有用的信息；把对比学习限制在 $z$ 空间，让 $h$ 保留更多信息，是 SimCLR 使用非线性投影头的原因。第二是**大 batch**：负样本越多，InfoNCE 的下界越紧，训练收敛越快；但大 batch 的显存开销很大，ImageNet 实验需要分布式 TPU。

## MoCo：用队列解耦负样本数 [71:20 - 74:34]

不是所有任务都负担得起大 batch，**MoCo**（momentum contrast）因此把负样本放进一个队列：队列跨 batch 保存历史负样本，采样时从队列里取，从而把负样本数量和 batch size 解耦。

代价是队列里的样本已经不在当前计算图里，无法反向传播。于是 MoCo 把编码器拆成两个：处理正样本的 **query encoder** 正常用梯度更新；处理负样本的 **key encoder** 不接收梯度，而是用动量从 query encoder 缓慢更新：

$$
\theta_k \leftarrow m\,\theta_k + (1-m)\,\theta_q
$$

MoCo v2 把两边的优点合起来：SimCLR 的非线性投影头和强数据增强，加上 MoCo 的动量队列，性能提升明显，而且不需要 TPU。

## 要点回顾

- **动机**：大规模训练需要海量人工标签；自监督学习用 pretext task 从数据自身构造监督信号，先训练 encoder，再迁移到下游任务。
- **框架**：无标签数据 → encoder → 表示 → decoder/classifier/regressor → 自动生成的标签；下游只训练浅层头。
- **评估**：代理任务表现、表示质量（linear probe、聚类、t-SNE）、鲁棒性与效率都重要，但最关键的是下游任务性能。
- **旋转预测**把视觉常识变成 4 路分类；RotNet 接近 ImageNet 预训练，远好于随机初始化。
- **相对位置**是 8 路分类；**拼图**从 $9!$ 种排列中挑出 64 种，把空间结构变成 64 路分类。
- **Inpainting** 用重建损失且只算在遮挡区域，并配合对抗损失缓解模糊；14 小时预训练就能明显超过随机初始化。
- **着色**在 Lab 空间做 $L\to ab$；**Split-brain** 做双向跨通道预测（如 RGB 与深度），下游用拼接特征。
- **视频着色**用参考帧 attention 保持颜色一致，并让跟踪、分割 mask 与关键点的传播“涌现”。
- **MAE** 用 75% 高遮挡、非对称 encoder/decoder 和只在遮挡 patch 上的 MSE，把重建预训练扩展到大规模；linear probing 衡量表示质量，fine-tuning 发挥上限。
- **对比学习**把同图不同视角拉近、不同样本推远；**InfoNCE** 是 N 路交叉熵，也是互信息下界，负样本越多下界越紧。
- **SimCLR** 用强增强、非线性投影头和超大 batch；**MoCo** 用负样本队列与动量 key encoder 解耦 batch 与负样本数，MoCo v2 结合两者。
