# 第 12a 讲 · 多模态模型（客座讲师 Wilson Yan）

> **CS294-158 深度无监督学习 · L12a** ｜ 讲者 Pieter Abbeel ｜ 53 分钟 ｜ [原视频](https://www.youtube.com/watch?v=A36T-MPihTo)

## 核心结论

本次讲座把多模态模型按架构分为双向、编码器-解码器、仅解码器和统一生成四类，核心问题是怎样把图像、视频、音频等模态接入以 Transformer 为主干的模型。CLIP 展示了对比式图文对齐的通用性，M3AE 说明联合掩码重建能改善表示，Flamingo/PaLI 走编码器-解码器路线，Frozen/LLaVA 则用仅解码器 LLM 加轻量投影层实现视觉指令跟随。规模、输入分辨率和数据质量是提升性能的三条主线；GPT-4V、Gemini 1.5 和 CoDi 等把能力推向复杂视觉推理、长视频理解和任意到任意生成。最后仍存在幻觉、视觉理解错误和视频层次理解不足等挑战。

## 多模态模型的范围与目标 [00:00 - 03:05]

多模态模型指能够整合多种模态的模型。当前主流模态是图像/视频、文本和音频；机器人场景还可能涉及触觉等传感数据。讲师指出，这些模态之所以占主导，很大程度上是因为数据可得性：抓取 YouTube 可同时得到视频和音频，文本和图像也相对容易采集。

学习多模态模型有两个理想结果：一是获得**多模态理解**，即同时理解图像和文本并学习它们如何相互对应；二是获得更好的**单模态理解**，即联合训练图像与文本后，能否反过来提升语言本身或图像本身的理解能力。

![多模态模型定义与理想目标幻灯片，列出图像、视频、文本、音频等模态](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0001_00-00-53.jpg)

课程大纲把内容分为双向多模态模型、编码器-解码器多模态模型、仅解码器多模态模型、多模态生成，以及 Transformer 中的并行化。前四类主要关注模型结构、训练方式和当前大模型的能力边界；并行化部分原本属于 LLM 课程但未展开，本次转写中也没有进一步讲解。

![本讲大纲幻灯片，列出双向、编码器-解码器、仅解码器多模态模型等五个主题](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0002_00-01-46.jpg)

## 双向模型：CLIP 的能力边界 [03:05 - 11:14]

这里的“双向”主要指非因果 Transformer；CLIP 被归入这一类。讲师提到 CLIP 的文本编码器严格说可能是因果的，但实际使用中并不强调这一点。CLIP 用对比目标学习图像编码器和文本编码器，原始论文最直接的应用是图像分类：把图像与不同类别名称的文本计算对齐分数，取最高分对应的类别。

与仅图像的预训练方法相比，CLIP 的一个重要优势是**对图像分布变化更鲁棒**。下图对比了 ResNet101 与 CLIP ViT-L：在 ImageNet 上两者准确率同为 76.2%，但在 ImageNet V2 上为 64.3% 对 70.1%，在 ImageNet Rendition 上为 37.7% 对 88.9%。

![CLIP与ResNet101在ImageNet、ImageNet V2和ImageNet Rendition上的图像分类准确率对比柱状图](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0003_00-03-32.jpg)

CLIP 还可以作为**排序器**使用。DALL·E 的做法是：给定文本描述，生成多张候选图像，分别计算图像与文本的 CLIP 对齐分数，再选分数最高的一对，通常效果不错。

在生成式应用里，Dream Fields 是一个早期文本到 3D 的例子：初始化 NeRF 参数，渲染出图像后送入 CLIP 图像编码器，计算其与给定文本的 CLIP 分数，再反传更新 NeRF 参数；此外还加入了一些 NeRF 特定的正则项来鼓励生成合理的 3D 结构。本质上就是优化 CLIP 分数。

![Dream Fields利用CLIP进行3D生成的示例：扶手椅、茶壶、蜗牛等物体按不同材质/风格生成](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0004_00-06-11.jpg)

另一条早期路线是在 VQGAN 的潜空间上做逐数据点优化：从随机 latent 出发，经 VQGAN 解码器生成图像，取裁剪区域送入 CLIP 图像编码器，与用户指定的文本对齐，然后对 VQGAN latent 做梯度上升。这里没有训练新网络，只使用预训练模型，因此会出现重复图案等伪影，原因之一是 CLIP 图像空间中存在一些对齐分数很高但视觉上很奇怪的区域。类似地，CLIP 也可以用于扩散模型的 guidance。

CLIP 更常见的用途是作为**预训练骨干**：在视觉语言模型中作为视觉编码器；在 Stable Diffusion 中作为文本编码器，通过交叉注意力条件化语言；在 CLIPort 中初始化机器人策略的图像编码器，使策略能根据“把红色方块放到绿色碗里”这类语言任务泛化到新物体、新颜色等 CLIP 分布内但下游策略未训练过的概念。通常只需少量任务微调数据，就能泛化到微调时未见的视觉概念。

![CLIP能力页：说明CLIP文本-图像编码器可作为预训练模型用于视觉语言模型、Stable Diffusion文本编码器及CLIPort，并提升泛化能力](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0005_00-08-14.jpg)

## M3AE：把 MAE 与 BERT 拼在一起 [11:14 - 16:09]

M3AE 的结构可以理解为 MAE 加 BERT：图像和文本 token 都做掩码，编码器只接收未掩码的图像块和未掩码的文本 token，解码器则尝试重建完整的图像-文本对。它既可以用图文对训练，也可以用于纯图像数据（文本全部掩码）或纯文本数据（图像全部掩码）；讲师提到该工作主要还是用图文数据训练。

![M3AE架构流程图：图像与文本分别经掩码后输入编码器，再经解码器重建，展示多模态掩码自编码器结构](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0006_00-11-29.jpg)

与只在图像上训练的 MAE 相比，M3AE 的线性探针准确率有明显提升，说明文本监督改善了视觉表示。微调时两者差距缩小，但 M3AE 仍有优势，并且可以只微调网络中较少的一部分就取得不错效果。

![M3AE与MAE在ViT不同规模下的线性准确率柱状图及微调块数与微调准确率折线图对比](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0007_00-13-15.jpg)

可视化显示，文本 token 的注意力能够落到图像中对应的区域；在表示空间的 t-SNE 图上，M3AE 的类别聚类也比 MAE 更清晰。讲师推测，ImageNet 的类别标签本身带有语言结构（例如某类狗、某类猫、卡车等），因此文本监督有助于学到更好的表示。

![M3AE多模态掩码重建示意图，展示图像局部区域与对应文本token的掩码预测](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0008_00-15-01.jpg)

![MAE与M3AE特征表示的t-SNE降维可视化对比，M3AE类别聚类更清晰](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0009_00-15-54.jpg)

## 编码器-解码器：Flamingo 的门控交叉注意力 [16:22 - 21:45]

Flamingo 的目标是在预训练语言模型上加入图像条件，但模型仍然只生成文本。它的做法是：用视觉编码器处理图像，再通过 Perceiver Resampler 把可变数量的视觉 token 转换成固定数量（讲师提到约为每张图 64 个 token）；然后在语言模型的各层之间插入 **GATED XATTN-DENSE** 层。该层以语言模型隐藏状态为 query，以图像 token 为 key/value 做交叉注意力，再接标准前馈层。

![Flamingo模型整体架构图，展示视觉编码器、Perceiver Resampler与冻结语言模型通过门控交叉注意力连接的流程](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0010_00-16-47.jpg)

“门控”体现在注意力和前馈层前都乘以 $\tanh(\alpha)$，其中门控参数初始化为 0。这样训练开始时模型行为与原始语言模型完全一致，随着训练进行，门控逐渐偏离 0，模型学习如何利用图像信息来预测文本。

![Flamingo中GATED XATTN-DENSE层的详细结构图及对应的PyTorch伪代码实现](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0011_00-18-33.jpg)

Flamingo 支持交错图文输入、少样本任务指定、VQA、OCR、把视频帧拼接后的视频问答以及围绕图像的多轮对话。定量上，它在不少任务上超过此前的零样本/少样本 SOTA，但部分任务仍低于针对基准微调过的专用模型；右侧的扩展曲线显示，随着语言模型部分规模增大，性能持续提升。

![Flamingo在多个视觉语言任务上的性能对比柱状图及不同参数量模型的少样本学习曲线](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0012_00-21-12.jpg)

## 编码器-解码器：PaLI 系列与“加 FLOPs”的两条路 [21:53 - 26:30]

PaLI 更接近标准的编码器-解码器结构：ViT 把图像 token 化成约 256 个 token，与语言 embedding 拼接后送入 Transformer 编码器，得到问题表示，再由解码器生成答案。它和原始 Transformer 编码器-解码器的主要区别是加入了图像输入。

PaLI 的扩展实验同时放大了模型规模和视觉组件规模（如 ViT-G、ViT-e），并发现提高输入图像分辨率能带来显著收益，尤其是 TextCaps 这类偏 OCR、文档阅读的任务。讲师把提升性能的方式概括为两条“加 FLOPs”的路径：增加模型参数量，或提高分辨率从而增加 token 数和序列长度；后者不改变参数量，但能增加计算量。

![PaLI系列模型在7个多模态基准任务上的绝对分数差异柱状图，对比不同规模与高分辨率阶段的效果](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0013_00-22-58.jpg)

后续的 PaLI-X 进一步扩大规模，并改进了训练方案：混合多种自监督/去噪目标，并在视觉编码器上加入 OCR 目标训练，以提升文本理解。PaLI-3 则改用 SigLIP 编码器，使用更好的数据混合、更高分辨率和渐进式高分辨率训练，最大分辨率约为 $1000 \times 1000$；最终以约 5B 参数接近 55B 的 PaLI-X 的性能。

![PaLI后续模型PaLI-X与PaLI-3的核心改进要点总结幻灯片](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0014_00-24-44.jpg)

## 仅解码器：Frozen、MiniGPT-4 与 LLaVA 系列 [26:34 - 33:35]

Frozen 是较早的仅解码器多模态模型：使用预训练语言模型，视觉侧是一个简单的 ResNet 类编码器；训练时冻结语言模型，只微调视觉编码器，输入图像后接 caption，用语言建模的下一 token 预测训练。仅解码器的好处是容易处理交错图文数据：可以把图像和文本都当作连续 token 流拼接；编码器-解码器结构则不太容易安排这种交错输入。

![冻结视觉编码器与语言模型、仅训练投影层的多模态架构图](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0015_00-27-23.jpg)

MiniGPT-4 和 LLaVA 是接近同期的工作：都以 Vicuna（本质上是 LLaMA 的指令微调版本）为语言模型并冻结，视觉侧分别使用 ViT + Q-Former（来自 BLIP-2）和 CLIP 图像编码器，中间用一个投影层把视觉特征映射到 Vicuna 的输入维度。大多数情况下只训练投影层，成本很低，但多模态理解效果已经不错。

LLaVA 的训练分两阶段：第一阶段冻结视觉和语言骨干，在约 60 万图文对上只训练投影层；第二阶段冻结视觉骨干，在高质量视觉指令数据上微调语言模型和投影层。由于微调了更大一部分模型，通常能获得更好的性能。

![LLaVA两阶段训练策略：先训练投影层，再微调语言模型与投影层](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0016_00-30-02.jpg)

LLaVA 1.5 的改进包括：分辨率从 224 提高到 336；投影层从线性层改为 MLP；使用更好的指令数据混合，以及更好的 VQA、OCR 数据。结果显示，7B 的 LLaVA 1.5 能超过一些更大的模型，说明高质量数据 curation 和训练细节非常重要。

![LLaVA 1.5 的改进点与多模态基准测试结果对比表](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0017_00-30-55.jpg)

LLaVA 1.6 的主要新意是处理高分辨率图像：当图像过大时，把它切成多个小分辨率 tile 分别编码，再展平拼接；同时额外输入一张下采样到 tile 尺寸的整图编码，以保留全局信息。这样既有高分辨率细节，又有全局概览，对文档理解等小字符场景尤其有用。该版本扩展到 34B，作为开源模型在多项基准上表现很强。

![LLaVA 1.6 与其他开源及闭源多模态模型在多项基准上的性能对比表](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0018_00-33-34.jpg)

## 闭源模型：GPT-4V 的能力与 Gemini 1.5 的长视频 [34:29 - 43:14]

GPT-4V 的架构没有公开。讲师根据其视觉 token 定价计算器推测：$512 \times 512$ 图像约为 255 个 token，低分辨率模式约为 85 个 token；当图像超过 $512 \times 512$ 时，会按最近的 512 倍数分块，例如 $513 \times 513$ 会被当作约 $1024 \times 1024$ 的四块处理。这与 LLaVA 1.6 的 tiling 思路相似，但只是推测。

能力方面，GPT-4V 可以充当视觉知识库，识别硬币、植物、地标；可以读复杂停车标志并做约束满足式推理；可以解几何题、回答考试题；也可以根据示意图生成代码。但它仍会 hallucinate，在生物、化学、脑部扫描等专业图像上有时对有时错，难以完全信任。

![GPT-4V 的 OCR 与图像文本理解能力：读取停车标志、解几何题、解读柱状图](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0019_00-36-43.jpg)

Gemini 1.5 侧重长上下文。讲师推测它可能使用离散 VQ 编码加 CoCa 类自编码器：CoCa 结合图像描述和文本-图像对比目标，可以粗略理解为“VQ 版本的 CLIP”，其 embedding 是离散的，并且可能在自编码器训练中加入了文本-图像监督。

![Gemini 1.5可能采用的VQ + CoCa模型架构推测](/coursenotes/cs294-158-deep-unsupervised-sp24/l12a-multimodal-models/kf_0020_00-38-47.jpg)

长视频能力用“needle retrieval”展示：在长视频的某些帧中插入“magic number”覆盖文字，测试模型能否在很长的时间范围内检索到该信息；结果可覆盖到约 10 小时。更自然的任务包括：给一段 40 分钟电影，询问某张纸片被取走的时间码；或给定手绘草图，检索视频中视觉对应的场景。长视频 QA 基准显示，输入帧数增加通常能提升能力，但较短（约 3 分钟）的视频基准会较早饱和。

## 多模态生成：从 CoDi 到统一图像/视频生成 [43:26 - 52:16]

此前的模型大多能条件化多种模态，但只生成一种模态；视频生成模型通常只生成视频，VideoPoet 是少数同时生成视频和音频的例子。多模态生成的目标是：用一个模型对任意模态组合做条件生成，例如输入图像和文本描述，生成视频或音频；或输入图像，生成文本描述。

CoDi 是一个任意到任意的生成模型，覆盖图像、视频、语言和音频。训练首先学习一个联合嵌入空间，并以文本为桥：冻结文本编码器，用文本-图像、文本-视频、文本-音频数据分别对齐各模态编码器，这些数据集大多已存在。然后训练各模态以文本为条件的生成模型；第二阶段再微调以接受非文本条件。由于各模态表示已经对齐，向量之间可以在一定程度上互换或插值，从而支持多模态条件生成。

另一类工作聚焦图像生成与图像描述的统一。Emu 的做法是把 CLIP 图像编码器输出的图像 token 与文本 token 拼接，除了语言下一 token 预测外，还回归目标图像的 CLIP embedding；但直接回归复杂分布会趋向均值，生成质量不高，因此再用一个微调过的 Stable Diffusion 以回归输出为条件生成高质量图像。LaVIT（转写中读作 Lait）则把 CLIP embedding 量化后做自回归预测；由于 CLIP 是有损编码器，还需要强解码器补回丢失的信息。模型何时生成图像、何时生成文本，主要由微调数据的类型和格式决定。

视频版本的结构类似：使用关键帧以及 MP4 中的运动向量/光流信息并量化，对离散 latent 做自回归下一 token 预测，再用微调过的 Stable Video Diffusion 作为解码器。讲师还介绍了其实验室的一个更简单方案：不用有损的 CLIP latent，而用 VQGAN，把图像 token 拼接起来；训练时交换文本 token 和视觉 token 的顺序，使模型有时做图像生成、有时做图像描述；聊天微调阶段再设计数据鼓励相应行为。

## 开放挑战 [52:31 - 52:58]

讲师最后指出，多模态模型仍普遍存在幻觉和视觉理解错误，视频理解尤其不足：如何层次化地理解一部电影如何运作、其中发生了什么，仍有大量工作要做。

## 要点回顾

- **多模态模型的目标**：整合图像、视频、文本、音频等模态；既追求多模态理解，也追求更好的单模态理解。
- **CLIP**：对比式图文对齐；可用于分类、生成候选排序、Dream Fields、VQGAN 潜变量优化、扩散 guidance，以及作为 VLM/Stable Diffusion/CLIPort 的预训练骨干；对分布变化更鲁棒。
- **M3AE**：MAE + BERT 式联合掩码重建；文本监督改善视觉表示，线性探针和聚类效果优于 MAE。
- **Flamingo**：冻结语言模型，插入门控交叉注意力层；Perceiver Resampler 固定视觉 token 数；门控初始为 0，训练中学习利用图像；只生成文本。
- **PaLI 系列**：ViT token + 语言 embedding 的编码器-解码器；规模、分辨率、数据质量和 OCR 目标都能提升性能；PaLI-3 以 5B 接近 55B 的 PaLI-X。
- **Frozen/LLaVA**：仅解码器 LLM 加视觉编码器和投影层；LLaVA 两阶段训练，1.5 改进分辨率和 MLP 投影，1.6 用 tiling 处理高分辨率图像。
- **GPT-4V/Gemini 1.5**：GPT-4V 具备强 OCR、视觉知识、考试和示意图理解能力，但会幻觉；Gemini 1.5 侧重长视频检索和长上下文理解。
- **多模态生成**：CoDi 以文本为桥学习联合嵌入空间，实现任意到任意生成；Emu/LaVIT 统一图像生成与描述，并用强解码器补足有损 CLIP latent；视频版用离散 latent 自回归加视频扩散解码器。
- **主要挑战**：幻觉、视觉理解错误，以及视频中层次化事件和电影叙事理解不足。
