# 第 7 讲 · 自监督学习：从去噪自编码器到 MAE

> **CS294-158 深度无监督学习 · L07** ｜ 讲者 Pieter Abbeel ｜ 152 分钟 ｜ [原视频](https://www.youtube.com/watch?v=s6xh6oKq1C0)

## 核心结论

自监督学习把数据本身当作监督信号，通过“留出一部分数据并预测它”来预训练可迁移的表示。重建式方法从去噪自编码器、图像修复、着色一路发展到 MAE：高掩码率、ViT、非对称编码器-解码器、只编码可见 patch 是其成功关键。把 MAE 推广到视频、音频和多模态时，必须针对数据冗余设计掩码策略，例如 VideoMAE 的 tube masking、SiamMAE 的首帧条件、Audio-MAE 的频谱图掩码。课程还强调：早期监督预训练仍常优于自监督，只有在更大规模数据上自监督的优势才明显显现。

## 1. 课程定位：从生成模型到可迁移表示 [00:00 - 02:38]

![CS294-158 深度无监督学习课程第7讲自监督学习的标题页，包含讲师姓名与照片](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0001_00-00-00.jpg)
*课程标题页：CS294-158 Deep Unsupervised Learning，Lecture 7 Self-Supervised Learning。*

- 课程此前覆盖了多类生成模型：它们可以被采样，用来生成与训练数据相似的新数据。
- 但很多任务真正需要的是一个**预训练模型**：先在大数据上预训练，再针对下游任务微调。
- 预训练模型的关键是**抽取好的表示**。生成模型也能学到表示，但本讲聚焦更直接地学习表示的替代路线。
- 历史上的做法是监督预训练：在 ImageNet 上监督训练，得到的特征迁移到其他数据集。但监督预训练需要大量人工标注，难以扩展。
- 自监督学习的评估协议通常是：先自监督预训练，然后**微调**或加**线性分类器**，用少量/中等数据与从头训练比较。

## 2. 表示为什么重要 [02:39 - 05:00]

![对比笛卡尔坐标与极坐标下同一数据分布的表示差异示意图](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0002_00-02-39.jpg)
*Goodfellow 的示例：同一组数据在笛卡尔坐标下需要复杂边界，在极坐标下更容易线性分开。*

- 表示决定了分类器学习的难易程度：好的表示让蓝圈和绿三角更容易被一条线分开；原始坐标下则需要更复杂的决策边界。
- 深度学习中的表示是逐层组合的：像素级输入 → 边缘检测 → 圆形/形状检测 → 更语义化的单元（如人脸）。
- 如果预训练网络里已经存在“笑脸/哭脸、睁眼/闭眼”等语义单元，那么在上面训练“高兴/难过”分类器就会很容易。
- 表示学习的目标：预训练一个神经网络，使其能通过微调在**下游数据有限**的任务上表现良好。生成模型可以实现这一点，但本讲看非生成式的替代方案。

## 3. 自监督学习的定义与动机 [05:00 - 09:08]

- 自监督学习可理解为一种“数据提供监督”的无监督学习：从数据中留出一部分，让网络预测被留出的部分。
- 关键不在于“留出”，而在于**选择留出什么、从哪个角度留出**，这决定了任务是否有效。
- Yann LeCun 的“蛋糕”比喻：
  - 自监督学习是蛋糕胚（cake génoise）：数据量最大，每个样本可提供数百万比特信息。
  - 监督学习是糖霜：少量人工标签，每个样本约 10 到 10,000 比特。
  - 强化学习是樱桃：奖励稀疏，数据量最小。
- 讲师指出，这一比喻在 2015/2016 年就预测了后来 ChatGPT 式“自监督预训练 → 监督微调 → RLHF”的训练序列。
- 问答中澄清概念：
  - **无监督学习**：不做显式数据标注的学习。
  - 无监督学习中可分为两类：**生成模型**与**自监督学习**。
  - 生成模型可以用训练好的模型再生数据；自监督学习通常不以再生数据为目的，而是学习表示。
- 自监督学习早在深度学习成功前就存在。当时很多人认为深度学习要靠自监督预训练加微调才能工作；AlexNet 完全监督却取得成功，曾让很多人意外。

![用 LeCake 蛋糕比喻强化学习、监督学习与自监督学习的数据信息量差异](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0003_00-07-36.jpg)
*LeCake：自监督学习是蛋糕胚，监督学习是糖霜，强化学习是樱桃。*

## 4. 去噪自编码器：把数据推离流形再拉回 [09:16 - 12:38]

- 去噪自编码器：对输入图像加噪，编码，再解码，目标是恢复原始图像。
- 常见噪声：高斯噪声、掩码噪声、椒盐噪声（激活饱和到最高/最低值）。
- 直觉：加噪把数据推离数据流形；去噪自编码器学习把数据拉回流形。
- 2010 年前后梯度难以在深层网络中传播，因此常**逐层训练**：先训练一层编码器和一层解码器，再堆叠，最后加监督损失微调。
- 这与扩散模型在概念上相似：都是加噪、去噪。扩散模型可看作去噪自编码器的现代化身；扩散模型也可预训练、微调，甚至用于零样本分割标注。

## 5. Context Encoders：图像修复式预训练 [12:44 - 16:14]

![Context Encoders 的编码器-解码器架构图，展示图像修复任务的流程](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0004_00-13-16.jpg)
*Context Encoders：编码器提取特征，解码器填补被挖空的图像区域。*

- 2016 年 Berkeley 的工作：不添加噪声，而是**挖掉图像区域**，让网络预测缺失内容。
- 可挖掉大块中心区域、分散的小区域，或按语义分割挖掉整个语义段。
- 架构：输入带空缺的图像 → 编码器 → 解码器 → 重建缺失区域；损失只定义在缺失区域。
- 损失设计很重要：
  - 只用重建损失：填补结果平滑、模糊，不够真实。
  - 只用对抗损失：填补区域看起来很真实，但可能与周围内容不兼容。
  - 重建损失 + 对抗损失：既真实又与上下文兼容。
- 转写提到，对抗损失主要作用在空白区域；重建损失帮助保证填进去的内容与外部兼容。

![Context Encoders 与其他预训练方法在分类、检测、分割任务上的定量对比表格](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0005_00-15-30.jpg)
*Context Encoders 与随机初始化、自编码器、其他自监督方法的分类/检测/分割对比。*

- 转写强调：在 ImageNet 上做填充式预训练，再评估分类以及 Pascal 上的检测、分割。
- 填充式预训练与其他自监督方法相比有竞争力，在分割任务上表现尤其好。
- 但**监督 ImageNet 预训练仍然更好**；这一趋势直到自监督在更大规模数据上训练后才改变。

## 6. 着色与跨通道预测 [16:35 - 21:58]

- 跨通道预测：如果有多个通道，可以挖掉部分通道，让网络重建其他通道。
- Lab 色彩空间：L 是灰度/亮度，a、b 是颜色分量。把彩色图像转成 Lab，输入 L，预测 a、b。
- 优点：互联网上所有彩色图像都可直接用于训练，预测任务定义明确。
- 如果下游任务关心颜色，这种预训练可能丢失一些颜色信息；但为了填色，网络会隐式学习大量颜色和图像结构知识。
- 损失函数选择很关键：
  - L2 回归会趋向平均值，难以建模多模态分布；例如车可能是蓝色、绿色或红色，L2 容易给出偏褐色的平均结果。
  - 逐像素分类：每个通道 256 个取值，用交叉熵，可以建模多模态分布，采样时可取到某个峰值。

![图像着色任务的L2回归损失与逐像素分类交叉熵损失公式](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0006_00-19-15.jpg)
*着色任务中的 L2 损失与逐像素分类交叉熵损失。*

$$L_2(\hat Y,Y)=\frac12\sum_{h,w}\left\|Y_{h,w}-\hat Y_{h,w}\right\|_2^2$$

$$L(\hat Z,Z)=-\frac1{HW}\sum_{h,w}\sum_q Z_{h,w,q}\log \hat Z_{h,w,q}$$

- Split-Brain Autoencoder：把 L 和 ab 分开，用两个网络互相预测对方缺失的通道，最后联合重建原图；需要额外损失防止网络直接恒等传递。
- 同类思路也用于 RGB-D：用 RGB 预测深度，或用深度预测 RGB 等跨模态预测。
- 视频着色：给网络第一帧彩色信息，后续帧只给灰度，让网络预测后续帧颜色。
  - 这把“从无到有预测颜色”的多模态问题，转成了“在第一帧中寻找对应关系”的问题，更接近单模态。
  - 效果很好，并可自动产生分割/跟踪能力：在第一帧标注要跟踪的对象，之后逐帧跟踪。

## 7. MAE：掩码自编码器 [21:59 - 30:36]

![MAE模型架构图，展示从输入到编码器、解码器再到重建目标的流程](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0007_00-22-47.jpg)
*MAE 架构：大编码器只处理可见 patch，小解码器补回缺失 patch。*

- 输入图像，随机掩码大量区域；编码器只编码未被掩码的 patch，得到嵌入；解码器把缺失位置补上占位符并解码，重建原图。
- 设计选择：**大编码器、小解码器**。因为真正要保留的是编码器；解码器训练完可丢弃，所以计算量应更多花在编码器上。
- 常见设置：只保留 25% 的 patch，掩码 75%；编码器只需处理四分之一的数据。
- 使用 Vision Transformer：
  - 每个 patch 经线性投影输入 Transformer，并加位置编码。
  - Transformer 可自然处理“某些 patch 缺失”的情况，不会为缺失位置做计算。
  - 线性投影尽量不把额外表示强加给编码器，让编码器自己学习表示。
- 转写指出，75% 是极高的掩码率，超出很多人预期；语言 BERT 通常只掩码 25%–30%，视觉中低掩码率尝试过但效果不佳。

![MAE在ImageNet验证集上的重建效果展示，对比了掩码图、重建图和原图](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0008_00-25-12.jpg)
*MAE 在 ImageNet 验证集上的重建示例：左为掩码图，中为重建，右为原图；示例掩码率 80%，196 个 patch 只保留 39 个。*

![不同掩码率对微调和线性探测准确率影响的折线图](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0009_00-26-39.jpg)
*掩码率研究：微调与线性探测在约 75% 掩码率附近表现较好。*

- 掩码率不能太低：否则任务太简单，网络可直接从可见 patch 复制内容，学不到真正语义表示。
- 掩码率也不能无限高：需要保证填回内容仍是相对单模态的预测；多模态分布更难训练。
- 为什么 MAE 简单却有效：
  - ViT 的灵活性使掩码 patch 处理自然；卷积网络处理掩码区域时仍会在空白处卷积，可能产生分布外行为，并与微调时不掩码的设置不匹配。
  - 高掩码率提供正确的归纳偏置，迫使网络学习语义。
  - 只计算 25% 的 patch，使训练更高效，可把编码器或数据规模扩大约四倍。
- 当时视觉自监督主流是对比学习；MAE 让“直接掩码并重建”的路线重新成为强基线。

## 8. BEiT：离散 token 空间的掩码预训练 [30:43 - 32:31]

- BEiT 也做 Transformer 的“填空”预训练，但先预训练一个离散 VAE/tokenizer，在离散 token 空间做掩码预测。
- 与 MAE 的差异：
  - BEiT 依赖预训练 tokenizer，部分表示学习过程不受端到端控制。
  - BEiT 掩码率较低。
  - BEiT 仍处理被掩码的 patch，没有把它们完全丢弃。
- 转写评价：BEiT 时间上早于 MAE，但细节设置不同；MAE 在“高掩码率 + 只编码可见 patch + 连续像素重建”等细节上做得更到位。

## 9. VideoMAE：视频中的管状掩码 [32:45 - 38:16]

![VideoMAE在Something-Something V2数据集上与SOTA方法的性能对比表格](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0010_00-35-27.jpg)
*VideoMAE 在 Something-Something V2 等视频基准上的对比结果。*

- 视频比图像更冗余：同一物体在相邻帧中位置相近。若逐帧随机掩码，网络可直接从前后帧复制内容，任务太简单。
- **Tube masking（管状掩码）**：在某一空间区域，跨多帧一起掩码；避免从相邻帧简单复制。
- 视频掩码率更高：90%–95%，因为视频冗余更强。
- 转写提到，VideoMAE 在仅约 3000 个视频上预训练也能得到好表示；数据质量比数据数量更重要；预训练数据与目标数据之间的分布偏移也很重要。
- 使用普通 ViT 主干，在 Kinetics-400 上达到 87.4%；在 Something-Something V2 等视频数据集上表现很好，且不使用额外标注数据。
- 问答讨论“掩码 vs 扩散噪声”：原则是尽可能多掩码，同时让填补任务仍存在相对单模态的解法；表示学习目前仍常用掩码自编码器。

## 10. SiamMAE：用首帧条件学习跟踪与对应 [38:21 - 45:25]

![SiamMAE的核心思想：通过掩码未来帧95%的patch来学习物体运动表示](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0011_00-40-30.jpg)
*SiamMAE 核心：首帧保持不变，未来帧掩码 95%，迫使网络学习物体运动与对象中心表示。*

- VideoMAE 的目标是学习语义表示（例如识别动作类别）；SiamMAE 的目标是学习跟踪、分割和对应关系。
- 做法：第一帧不掩码，编码并保留其特征；未来帧掩码约 95%，让网络根据少量可见 patch 推断其余部分。
- 直觉：少量可见 patch 告诉网络“物体如何运动”，网络需要把其余部分也按一致运动补全，从而学会对应关系。
- 下游任务：
  - 视频对象分割
  - 人体姿态关键点传播
  - 语义部件传播
- 转写称 SiamMAE 在这些任务上达到当时最优。

![视频对象分割与姿态估计任务在多种场景下的可视化效果展示](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0012_00-42-04.jpg)
*视频对象分割与姿态/部件跟踪的可视化效果。*

![SiamMAE与先前方法在视频对象分割、人体姿态传播等任务上的性能对比表](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0013_00-45-34.jpg)
*SiamMAE 与先前方法在视频对象分割、人体姿态传播、语义部件传播上的对比。*

- 推理时逐帧与首帧特征匹配：编码首帧特征，未来帧编码后与首帧特征匹配，再把匹配结果投影回分割。
- 首帧标注可以手动选择区域，也可先用分割器分割再选择要跟踪的对象。
- 训练数据需要连续帧；若视频中有切镜，应把不同场景切成独立片段，否则跨场景填空无法完成。
- 这说明即使叫“自监督/无监督”，仍需要一定的数据策展，只是很多策展可以脚本化。

## 11. Audio-MAE：频谱图上的 MAE [45:54 - 47:48]

- 把音频转成频谱图：对时间窗口做傅里叶变换，得到频率域表示；频谱图看起来像图像，因此可直接套用 MAE。
- 编码器只处理未被掩码的 token；解码器重排 token、填补空缺并重建。
- 与图像 MAE 的差异：解码器使用**局部窗口注意力**，因为音频数据中局部性很重要。
- 在目标数据上对编码器采用较低掩码率，使表示更接近下游数据分布。
- 转写称 Audio-MAE 在 6 个音频/语音分类任务上达到新的最优，超过使用外部监督预训练的其他模型。
- 要点：最简单的“填空”思想在音频上也有效。

## 12. MultiMAE 与 M3AE：多模态掩码预训练 [47:48 - 54:16]

![MultiMAE 架构图，左侧为多模态预训练流程，右侧为单模态和多模态微调流程](/coursenotes/cs294-158-deep-unsupervised-sp24/l07-self-supervised-learning/kf_0014_00-48-46.jpg)
*MultiMAE：多模态输入（如 RGB、深度、语义分割）随机采样可见 patch，编码后重建缺失模态。*

### MultiMAE

- 对多种模态（RGB、深度、语义分割等）使用不同掩码率和掩码组合，让网络学习填补其他模态。
- 语义分割作为输入通道并不完全“自监督”，但转写解释：可使用现成分割算法生成伪标签；让网络在训练时也处理语义信息，会迫使表示更努力地学习。
- 编码器只处理未被掩码的 token；解码器较浅；不同模态使用伪标签。
- 在 ImageNet-1K 分类与语义分割数据集上表现良好；也可做跨模态预测，例如 RGB→深度/语义、深度→RGB/语义、语义→RGB/深度。

### M3AE：图文多模态 MAE

- 当时图文多模态表示学习的主流是对比学习（如 CLIP 式），缺点是必须使用成对数据；未配对数据贡献有限。
- M3AE 在图文描述数据上做多模态 MAE 预训练，在 ImageNet-1K 线性分类上显著优于仅用图像预训练。说明文本语义信息帮助图像表示学习。
- 掩码率：即使语言侧也使用高掩码率（转写提到 75%），与当时 BERT 式约 30% 的常见设置不同；可能是因为图像提供了互补信息。
- 架构：图像 patch 与文本 token 输入编码器；解码器轻量，遵循 MAE 的经验；解码器重建图像、文本或图文对。
- 与 MAE 比较：微调准确率严格更好；线性探测准确率提升更大，说明学到的底层表示更好；若网络很大，MAE 微调后也能接近。
- 问答：图文掩码是随机的，没有机制保证未掩码文本一定描述未掩码图像区域；依靠高掩码率仍能恢复。

### 多视角掩码世界模型

- 转写最后提到 Multi-view Masked World Models：多相机看同一场景，掩码某些视角，让网络填补其他视角。
- 这需要较深的语义与几何理解；转写说 Philipp 后续会结合视觉机器人控制展开，但给定材料未包含该部分。

## 13. 视觉常识任务：相对位置与旋转 [54:26 - 63:18]

- 在 MAE 之前，很多人认为“重建图像”不适合视觉表示学习，于是探索其他自监督任务。
- **相对 patch 预测**：给一个中心 patch，再给另一个 patch，让网络分类后者相对中心的位置（中心给定，预测其余候选位置，常见 8/9 类设置）。
  - 要预测猫的耳朵相对鼻子和眼睛的位置，网络需要理解猫的语义结构，而不能只看局部纹理。
  - 使用分类器比重建整幅图像计算更便宜。
  - 设计上要避免“靠局部纹理匹配”或“靠图像边缘伪影”作弊：候选位置不要紧邻，也不要总在图像边缘；可对 patch 位置加 jitter，并随机化颜色/光照模式。

## 要点回顾

- 自监督学习的核心是“数据提供监督”：留出一部分数据，让网络预测它；关键是选择留出什么。
- 表示质量决定下游任务难度；预训练后常用微调或线性分类器评估。
- 去噪自编码器通过加噪/去噪学习流形结构，是扩散模型的概念前身。
- Context Encoders 用图像修复做预训练，重建损失 + 对抗损失缺一不可；但监督预训练仍长期更强。
- 着色任务把颜色预测转成 Lab 空间跨通道预测；L2 易产生平均色，逐像素分类交叉熵更适合多模态分布。
- MAE 的成功公式：高掩码率（约 75%）、ViT、大编码器/小解码器、只编码可见 patch、线性投影。
- BEiT 在离散 token 空间做掩码预测，依赖预训练 tokenizer，掩码率较低且仍处理掩码 patch。
- VideoMAE 用 tube masking 和 90%–95% 掩码应对视频冗余；数据质量比数量更重要。
- SiamMAE 用首帧条件 + 未来帧 95% 掩码学习跟踪与对应，在视频对象分割、姿态/部件传播上达到 SOTA。
- Audio-MAE 把频谱图当图像做 MAE，解码器加局部窗口注意力。
- MultiMAE 做多模态跨模态重建；M3AE 用图文 MAE 提升图像表示，高掩码率在语言侧也有效。
- 视觉常识任务包括相对 patch 位置预测与旋转预测；设计时要避免局部纹理和边缘伪影等捷径。
